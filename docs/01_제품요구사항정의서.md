# 01. LabPet 제품요구사항정의서

## 1. 제품 개요
`LabPet`은 Windows 바탕화면 위 투명 창에서 3D 커스텀 캐릭터를 렌더링하고, 개인 성장·시스템 오디오 반응·서버리스 LAN P2P 소셜 기능을 제공하는 `.NET 10` WPF 데스크톱 펫 애플리케이션입니다.

## 2. 단계별 구현 로드맵
- **Phase 1 (현재)**: 솔루션 스캐폴딩, `LabPet.Shared` 공용 모델·프로토콜·`ISocialTransport`, 3종 절차적 3D 캐릭터, 360도 턴테이블 온보딩, 투명 펫 창(드래그·클릭 투과·트레이), `%AppData%\LabPet\` 원자적 저장소
- **Phase 2 (예정)**: `NAudio` 루프백 오디오 FFT 분석기, 캐릭터별 3D 리듬 애니메이션, 개인 성장 루프(활동량·뽀모도로·상점)
- **Phase 3 (예정)**: `LanP2pTransport` 구현 (물리 어댑터 필터링 UDP 탐색, `protocolVersion` 호환 배지, TCP 친구 신청·HMAC 인증, 말풍선 메시지, 30Hz 노래 따라하기)
- **Phase 4 (예정)**: Velopack 진입점 및 `UpdateService`, GitHub Actions 차분 릴리스 파이프라인, 시작 프로그램 등록, 방화벽/SmartScreen 및 GCP 확장 문서
