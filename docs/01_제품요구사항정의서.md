# 01. LabPet 제품요구사항정의서

## 1. 제품 개요
`LabPet`은 Windows 바탕화면 위 투명 창에서 3D 커스텀 캐릭터를 렌더링하고, 개인 성장·시스템 오디오 반응·서버리스 LAN P2P 소셜 기능을 제공하는 `.NET 10` WPF 데스크톱 펫 애플리케이션입니다.

## 2. 단계별 구현 로드맵
- **Phase 1 (구현 완료)**: `LabPet.Shared` 공용 모델·프로토콜·`ISocialTransport`, 절차적 3D 캐릭터 4종(`v0.1.5` 기준), 360도 턴테이블 온보딩, 투명 펫 창(드래그·클릭 투과·트레이), `%AppData%\LabPet\` 원자적 저장소
- **Phase 2 (구현 완료)**: `NAudio` 루프백 오디오 FFT 분석기, 캐릭터별 3D 리듬 애니메이션, 개인 성장 루프(활동량·뽀모도로·상점)
- **Phase 3 (구현 완료)**: `LanP2pTransport` 구현 (물리 어댑터 필터링 UDP 탐색, `protocolVersion` 호환 배지, TCP 친구 신청·HMAC 인증, 말풍선 메시지, 30Hz 노래 따라하기)
- **Phase 4 (구현 완료)**: Velopack 진입점 및 `UpdateService`, GitHub Actions 차분 릴리스 파이프라인, 시작 프로그램 등록, 방화벽/SmartScreen 및 GCP 확장 문서

펫은 한 인스턴스로 실행한다. 두 번째 실행에는 안내를 표시하고 두 번째 프로세스만 종료한다. 친구 목록을 보는 중 새 친구가 등록되거나 메시지가 오가도 목록을 계속 사용할 수 있으며, 각 상호작용의 보상을 반영한다.

업데이트 안내, 친구 신청, 최근 메시지가 함께 들어오면 본문을 줄바꿈해 표시한다. 일반 말풍선은 최신 메시지를 최대 5개까지 표시한다. 캐릭터에 마우스를 올리면 하단에 펫 이름과 레벨이 표시된다.

빠른 메시지는 보낼 친구의 행 아래에서 작성하며, 입력칸과 전송 버튼 위에서는 전송 후에도 이어서 입력할 수 있다. 포인터가 입력 영역을 벗어나면 접힌다. 이름·레벨 바 아래에서 펫 크기를 50~150% 사이로 조절하고, 펫·친구 오버레이·말풍선의 투명도를 함께 조절한다.

본체와 친구 창에 모양이 같은 펫을 표시할 때 3D 메시 데이터를 공유한다. 각 창은 표시하는 동작에 필요한 효과를 생성한다.
