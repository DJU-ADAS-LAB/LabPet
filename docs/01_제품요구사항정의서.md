# 01. LabPet 제품요구사항정의서

## 1. 제품 개요
`LabPet`은 Windows 바탕화면 위 투명 창에서 3D 커스텀 캐릭터를 렌더링하고, 개인 성장·시스템 오디오 반응·서버리스 LAN P2P 소셜 기능을 제공하는 `.NET 10` WPF 데스크톱 펫 애플리케이션입니다.

## 2. 단계별 구현 로드맵
- **Phase 1 (구현 완료)**: `LabPet.Shared` 공용 모델·프로토콜·`ISocialTransport`, 절차적 3D 캐릭터 4종(`mochi_spirit`, `chibi_cat`, `fluffy_cloud`, `fluffy_puppy`) 및 전 치장 아이템 기본 무료 개방, 360도 턴테이블 온보딩, 투명 펫 창(드래그·클릭 투과·트레이), `%AppData%\LabPet\` 원자적 저장소
- **Phase 2 (구현 완료)**: `NAudio` 루프백 오디오 FFT 분석기(15초 음악 활성 홀드), 캐릭터별 3D 리듬·타이핑 미니 키보드 애니메이션, 개인 성장 루프(활동량·뽀모도로) 및 4종 코인 게임(하이로우 · LAN 가위바위보 · LAN 10초 타이핑 대결 · 연구실 공동 사다리타기)
- **Phase 3 (구현 완료)**: `LanP2pTransport` 구현 (물리 어댑터 필터링 UDP 탐색, `protocolVersion` 호환 배지, TCP 친구 신청·HMAC 인증, 말풍선 메시지, 30Hz 노래 따라하기, 친구 3D 프리뷰 및 바탕화면 방문 창 `VisitorPetWindow`)
- **Phase 4 (구현 완료)**: Velopack 진입점 및 `UpdateService`(5분 폴링 + LAN 상위 버전 힌트 + `--autostart` 무인 업데이트), GitHub Actions 차분 릴리스 파이프라인, 시작 프로그램·방화벽 자동 등록 및 GCP 확장 문서

펫은 한 인스턴스로 실행한다. 두 번째 실행에는 안내를 표시하고 두 번째 프로세스만 종료한다. 친구 목록을 보는 중 새 친구가 등록되거나 메시지가 오가도 목록을 계속 사용할 수 있으며, 각 상호작용의 보상을 반영한다.

업데이트 안내, 친구 신청, 게임 도전, 최근 메시지는 펫 상단 전용 `Popup`(`SpeechBubblePopup`)에 표시되어 메시지가 생성·소멸되어도 펫 창의 높이나 캐릭터 위치가 흔들리지 않는다. 일반 말풍선은 최신 메시지를 최대 5개까지 표시한다. 받은 친구 메시지는 왼쪽에 보낸 친구 펫의 3D 초상을 함께 보여 준다. 캐릭터에 마우스를 올리면 하단에 펫 이름·레벨과 크기(50~150%)·투명도(25~100%) 조절바가 표시되며, 바탕화면에 데려온 방문 친구 펫도 동일한 크기·투명도를 공유한다.

빠른 메시지는 보낼 친구의 행 아래에서 작성하며, 입력칸에 키보드 커서(포커스)가 살아있는 동안에는 마우스 포인터가 오버레이 밖으로 벗어나도 닫히지 않는다. 포커스가 해제된 뒤 포인터가 영역 밖에 있으면 자연스럽게 접힌다. 친구 오버레이는 펫 창과 외형 조절 영역 바깥에 배치한다.

본체와 친구 창에 모양이 같은 펫을 표시할 때 3D 메시 데이터를 공유한다. 각 창은 표시하는 동작에 필요한 효과를 생성한다.
