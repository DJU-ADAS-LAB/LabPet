# 03. 네트워크 프로토콜 및 보안 명세

## 1. 포트 및 프로토콜 상수
정의 파일: [ProtocolConstants.cs](../src/LabPet.Shared/Protocol/ProtocolConstants.cs)

| 상수 | 값 | 용도 |
| --- | --- | --- |
| `CurrentProtocolVersion` | `1` | 현재 클라이언트 송신 프로토콜 버전 |
| `MinSupportedProtocolVersion` | `1` | 하위 호환 수용 최소 버전 |
| `UdpDiscoveryPort` | `45678` | LAN 피어 탐색(`HELLO`) 브로드캐스트 |
| `UdpMusicFramePort` | `45679` | 30Hz 노래 따라하기 오디오 프레임 유니캐스트 |
| `TcpControlPort` | `45680` | 친구 신청/수락, 말풍선 메시지, 구독 제어 |

## 2. 프로토콜 버전 호환성 정책
- `peerProtocolVersion < MinSupportedProtocolVersion` → `PeerOutdated` (상대 업데이트 필요)
- `peerProtocolVersion > CurrentProtocolVersion` → `LocalOutdated` (로컬 업데이트 필요)
- 호환 범위를 벗어난 피어는 연결을 차단하고 UI에 업데이트 필요 상태를 표시한다(Phase 3 구현 예정).

## 3. 친구 인증 및 HMAC-SHA256 서명
정의 파일: [PacketSigner.cs](../src/LabPet.Shared/Protocol/PacketSigner.cs)
- 친구 수락 시 `RandomNumberGenerator.Fill`로 32바이트 `pairSecretBase64`를 생성한다.
- 친구 전용 제어 패킷과 UDP 오디오 프레임은 정규화 문자열에 대해 `HMACSHA256.HashData` 서명을 첨부하고, 수신 측은 `CryptographicOperations.FixedTimeEquals`로 상수 시간 검증을 수행한다.
