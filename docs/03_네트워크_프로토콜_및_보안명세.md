# 03. 네트워크 프로토콜 및 보안 명세

## 1. 포트 및 프로토콜 상수
정의 파일: [ProtocolConstants.cs](../src/LabPet.Shared/Protocol/ProtocolConstants.cs)

| 상수 | 값 | 용도 |
| --- | --- | --- |
| `CurrentProtocolVersion` | `3` | 친구 등록 키 합의, 서명된 ACK, 탐색 후보 검증 |
| `MinSupportedProtocolVersion` | `3` | v1·v2는 제어 연결 거부 및 업데이트 필요 판정 |
| `UdpDiscoveryPort` | `45678` | LAN 피어 탐색(`HELLO`) 브로드캐스트 |
| `UdpMusicFramePort` | `45679` | 30Hz 노래 따라하기 오디오 프레임 유니캐스트 |
| `TcpControlPort` | `45680` | 친구 신청/수락, 말풍선 메시지, 노래 따라하기 구독 제어, 친구 코인 게임 이벤트(`PacketType.GameEvent`) |
| `MusicHostSilenceTimeoutMs` | `180000` | 노래 따라하기 호스트 완전 무음 시 자동 해제 기준(3분) |
| `MusicFrameTimeoutMs` | `15000` | 노래 따라하기 UDP 프레임 미수신 시 로컬 모드 복귀 기준(15초) |

## 2. 프로토콜 버전 호환성 정책
- `peerProtocolVersion < MinSupportedProtocolVersion` → `PeerOutdated` (상대 업데이트 필요)
- `peerProtocolVersion > CurrentProtocolVersion` → `LocalOutdated` (로컬 업데이트 필요)
- 호환 범위를 벗어난 피어의 TCP 제어 연결은 닫는다. 미등록 피어의 탐색 목록에는 호환 상태를 표시한다. 등록된 구버전 친구는 모두 업데이트하기 전까지 인증된 온라인 상태로 표시되지 않는다.

눈던지기는 0.3.13 이상에서 기존 친구 인증·암호화 `PetInteraction`으로 전송한다. 같은 투척은 LAN/GCP 전환에도 동일한 `EventId`를 사용한다. 미지원 상대에는 눈던지기를 전송하지 않고 알 수 없는 유형은 거절한다. [전송 계약](../src/LabPet.Shared/Transport/ISocialTransport.cs)

게임 초대와 시작 응답은 기존 암호화 `GameEvent`로 전달한다. 발신자가 `InviteExpiresAtUtc`를 지정하며 응답도 같은 시각과 세션·게임·참가비를 되돌린다. `InviteReason`은 거절·취소 사유에 사용한다. ACK 뒤 상대 앱의 `registered` 응답이 있어야 등록 성공으로 표시한다. 호환되지 않는 이전 초대 형식은 앱 업데이트가 필요하다. GCP 서버는 예전과 같이 암호문을 중계한다. [게임 패킷](../src/LabPet.Shared/Protocol/Packets.cs), [공용 초대 상태](../src/LabPet.Client/ViewModels/CoinGamesViewModel.Invites.cs)

## 3. 친구 인증, AES-256-GCM 암호화 및 로컬 비밀키 보호
정의 파일: [PacketSigner.cs](../src/LabPet.Shared/Protocol/PacketSigner.cs), [PacketCrypto.cs](../src/LabPet.Shared/Protocol/PacketCrypto.cs), [Packets.cs](../src/LabPet.Shared/Protocol/Packets.cs), [LocalSecretProtector.cs](../src/LabPet.Client/Storage/LocalSecretProtector.cs)
- 수신자가 수락하면 두 앱은 임시 P-256 ECDH 공유값과 HKDF-SHA256으로 확인 키와 장기 친구 키를 각각 파생한다. 신청 ID, 양쪽 펫 ID와 공개키, 신청 본문이 파생에 묶인다. 두 앱은 공개키와 확인 서명을 교환하며 장기 친구 키는 로컬에서 생성한다. 신청의 유효 시간은 3분이다. [친구 등록](../src/LabPet.Client/Network/LanP2pTransport.Pairing.cs)
- 최초 등록에서 키 확인은 양쪽이 같은 키를 합의했는지 검증한다. 상대의 신원을 독립적으로 확인하는 단계가 없으므로 최초 등록 중 능동적 중간자 공격에 대한 방어는 제공하지 않는다.
- 신청자는 현재 대기 중인 신청과 수락 서명을 검증한 뒤 등록한다. 수락자는 확인 키로 서명된 ACK를 확인한 뒤 등록한다. 같은 신청의 확인 재시도는 등록 이벤트를 다시 발생시키지 않는다. 이미 등록된 친구의 키는 새 요청으로 교체하지 않는다. 업데이트 시 기존 DPAPI 키를 계속 사용하므로 구버전에서 이미 유출된 키는 업데이트만으로 교체되지 않는다.
- 친구 제어 패킷은 AES-256-GCM 암호화와 HMAC-SHA256 서명을 요구한다. ACK는 송신 메시지 ID, 상대 ID, 프로토콜 버전 및 인증 키와 연결한다. 암호화되지 않은 탐색 HELLO는 검증 후보로만 사용하고, 인증된 TCP 프레즌스 교환 뒤에 친구 IP·포트·이름·외형과 온라인 상태를 갱신한다. [TCP 제어](../src/LabPet.Client/Network/LanP2pTransport.Control.cs), [프레즌스 검증](../src/LabPet.Client/Network/LanP2pTransport.Presence.cs)
- TCP는 시각 오차 ±2분을 허용하고 친구별로 최대 1,024개 요청 ID와 처리 결과를 메모리에 보관한다. 내용이 같은 요청을 다시 받으면 같은 결과를 응답하며, 상태 변경은 한 번 실행한다. 앱을 완전히 재시작하면 메모리 재전송 기록은 초기화된다. UDP 음악은 HMAC 검증 후 구독 ID와 송신 순번을 확인한다. [재전송 검증](../src/LabPet.Client/Network/ControlReplayWindow.cs)
- TCP 수신은 16개 워커와 연결별 4초의 비동기 제한 시간을 사용한다. 기본 포트 충돌 시 LAN 연결이 시작되지 않으며 환경 안내를 표시한다.
- `friends.json`과 정상 JSON 백업의 키는 현재 Windows 사용자 계정의 DPAPI로 보호한다. 평문 백업도 변환한다. DPAPI에서 읽을 수 없는 암호문은 보존하고 원래 사용자 계정에서 복구하도록 안내한다. 본 파일과 백업이 모두 읽히지 않으면 덮어쓰지 않는다. [친구 저장소](../src/LabPet.Client/Storage/JsonAppDataStore.cs)

## 4. LAN 게임의 신뢰 범위

- 로컬 성장 값과 0.3.16 검사 완료 기록은 같은 Windows 계정의 DPAPI 스냅샷에서 펫 ID와 함께 검증한다. 확인된 검사 이후에는 검사 전 백업보다 해당 펫의 완료 스냅샷을 우선한다. 검증에 실패하면 평문 성장 값을 복구 자료로 사용하지 않으며, 손상본을 보존하고 코인 적립·소비·판돈 정산을 제한한다. 외형과 설정은 분리해 저장한다. 복구 여부는 로컬에서 판단하며 서버 인증·친구 키 저장·네트워크 규격은 기존 경로를 사용한다. [보호 저장소](../src/LabPet.Client/Storage/JsonAppDataStore.cs)

- 가위바위보는 양측이 난수를 포함한 선택 해시를 먼저 교환하고, 공개된 선택이 해시와 일치할 때만 정산한다. 상대가 공개를 중단하면 시간 제한 후 미완료 로컬 라운드의 코인을 반환한다.
- 타이핑 결과는 상대가 보낸 점수 대신 세션 문장과 제출 기록으로 재계산한다. P2P에서는 사람이 입력했는지 또는 자동화가 입력했는지 판별할 수 없다.
- 사다리 게임은 초대 응답 완료 후 방장의 참가자 확정, 중복 없는 시작 위치 선택 완료, 방장 PC의 암호학적 난수(`RandomNumberGenerator`)·Fisher–Yates 셔플 보드 생성·브로드캐스트 순서로 진행하며, 각 클라이언트가 가로줄 충돌·상품 구성·전원 결과(`Outcomes`) 일관성을 검증한다(Commit-Reveal 및 중앙 서버 미사용). 하강 도착 시 결과를 개별 공개하고 유료 모드(`WagerCoins > 0`)만 정산·환불 1회 가드를 적용한다. [코인 게임 처리](../src/LabPet.Client/ViewModels/CoinGamesViewModel.Ladder.cs), [사다리 엔진](../src/LabPet.Client/Games/LabLadderEngine.cs)

## 5. GCP 실시간 중계 인증 · E2EE · 메시지 비저장 정책
정의 파일: [RemoteRelayModels.cs](../src/LabPet.Shared/Protocol/RemoteRelayModels.cs), [SocialHub.cs](../src/LabPet.Server/Hubs/SocialHub.cs), [IdentityRegistryStore.cs](../src/LabPet.Server/Storage/IdentityRegistryStore.cs), [GcpSignalRTransport.cs](../src/LabPet.Client/Network/GcpSignalRTransport.cs), [HybridTransportRouter.cs](../src/LabPet.Client/Network/HybridTransportRouter.cs)
- **기기 ECDSA P-256 챌린지-응답 인증**: 클라이언트는 `%AppData%\LabPet\device_identity.json`(개인키 DPAPI 보호)에 저장된 기기 ECDSA 키쌍으로 `/api/auth/challenge`의 1회용 논스(TTL 60초)에 서명해 `/api/auth/token`으로부터 HMAC-SHA256 단기 Bearer 토큰을 발급받는다. 동일 `PetId`에 다른 공개키로 접속하려는 사칭 시도는 `403 Forbidden`으로 차단한다.
- **최소 영속 데이터 범위 및 메시지 비저장**: 서버는 `/var/lib/labpet/registry.json`에 `PetId ↔ PublicKey` 바인딩 및 승인된 상호 친구 관계만 최소 저장하며(`SaveAtomicLocked` 저장 성공/실패 반환 및 오류 로깅), **채팅 메시지 본문·빠른 반응·게임 페이로드·오프라인 쪽지는 디스크/메모리 큐/DB 어디에도 저장하지 않는다.** 수신자 오프라인 시 즉시 `RECIPIENT_OFFLINE`을 반환하고 폐기한다.
- **친구 신청·수락 멱등성 및 오류 전파**: [PendingFriendRequestStore.cs](../src/LabPet.Server/Services/PendingFriendRequestStore.cs)는 만료 툼스톤과 승인 완료(`MarkApproved`) 상태를 구분해 만료(`PAIRING_REQUEST_EXPIRED`)와 미존재(`PAIRING_REQUEST_UNKNOWN`)를 분리 반환하며, 수락 ACK 유실 시 TTL 내 수락자 재시도를 허용해 양측 동일 친구 키를 보장한다. [SocialHub.cs](../src/LabPet.Server/Hubs/SocialHub.cs)는 신청·수락·거절·ACK·친구 등록 단계마다 요청 ID·단계·오류 코드·처리 시간만 구조화 로그로 기록한다(메시지 본문·토큰·개인키·ECDH 비밀값·친구 키 비노출).
- **클라이언트 단계별 결과·오류 전파 및 로컬 저장 일관성**: [FriendOperationModels.cs](../src/LabPet.Shared/Transport/FriendOperationModels.cs), [ISocialTransport.cs](../src/LabPet.Shared/Transport/ISocialTransport.cs), [SocialCoordinatorService.cs](../src/LabPet.Client/Social/SocialCoordinatorService.cs)는 신청 전송·원격 수신·ACK 검증·로컬 영속 저장 단계와 표준 오류 코드를 상위 계층으로 손실 없이 전달한다. 수락 처리 완료 전 `friends.json` 영속 저장을 직접 대기하고, 저장 실패 시 메모리 친구 목록과 전송 계층 캐시를 롤백하며 성공으로 표시하지 않는다. `GcpSignalRTransport`는 서버 `/health`의 `bootId` 변화로 서버 재시작을 감지해 미완료 발신 요청을 정리한다.
- **종단 간 암호화(E2EE) 및 공개 탐색 프라이버시**: HTTPS/WSS 전송 계층 보안에 더해, 비친구 온라인 피어 탐색 목록에서는 공개 프로필(`OwnerName`/`PetName`/`Appearance`/`Level`)만 노출하고 `IsMusicActive`/`IsSleeping`/`FriendCode`는 비노출(`false`/빈 값)로 마스킹한다. 친구 제어 패킷은 기존 P-256 ECDH로 합의한 `PairSecretBase64`로 클라이언트 측에서 `AES-256-GCM + HMAC-SHA256` 암호화·서명한 뒤(`IsEncrypted = true`) 중계한다. 서버는 `AreMutualFriends`와 `SenderPetId == 인증된 PetId`, 크기/레이트 리밋, `MessageId` 중복만 검증하고 평문을 열람·저장하지 않는다.
- **하이브리드 경로 선택 및 중복 방지**: `HybridTransportRouter`는 LAN 온라인 피어에 대해 LAN P2P를 우선 사용하고 일시적 실패(`IsTransient`)이거나 외부 네트워크일 때만 GCP 중계로 전환하며(확정적 거부 시 불필요한 폴백 차단), LAN/GCP 간 동일 상대 중복 발신을 교차 차단한다. 양측 경로 동시 수신 시 바운디드 중복 캐시로 이벤트를 1회만 전달한다.

## 6. LAN P2P 및 GCP 중계 DoS 방어 정책
정의 파일: [LanDosProtectionOptions.cs](../src/LabPet.Client/Network/LanDosProtectionOptions.cs), [BoundedRateLimiter.cs](../src/LabPet.Client/Network/BoundedRateLimiter.cs), [SnowballInteractionService.cs](../src/LabPet.Client/Social/SnowballInteractionService.cs), [ServerConnectionOptions.cs](../src/LabPet.Client/Network/ServerConnectionOptions.cs), [ServerOptions.cs](../src/LabPet.Server/Options/ServerOptions.cs), [LabPetServerHost.cs](../src/LabPet.Server/LabPetServerHost.cs), [SocialHubRateLimitFilter.cs](../src/LabPet.Server/Hubs/SocialHubRateLimitFilter.cs), [RemoteMusicRelayDispatcher.cs](../src/LabPet.Server/Services/RemoteMusicRelayDispatcher.cs), [ServerOverloadProtectionService.cs](../src/LabPet.Server/Services/ServerOverloadProtectionService.cs)

### LAN P2P 방어
- **역직렬화 이전 크기·빈도 제한**: UDP 탐색(`4,096B`, IP당 `8/초` → 전역 `60/초`), UDP 음악(`1,024B`, IP당 `120/초` → 전역 `400/초`, 인증 친구당 `45/초`), TCP 제어(`16KB`, IP당 `30/초` → 전역 `120/초`)를 JSON 역직렬화 이전에 차단한다.
- **TCP 동시 연결 분리 및 친구 자원 예약**: 전체 TCP 슬롯 `16`개 중 `8`개를 인증된 친구 IP 전용으로 예약하고 비친구 연결은 전역 `8`개·IP당 `3`개(친구 IP당 `6`개)로 제한한다.
- **미인증 캐시 상한·병합 및 Dispatcher 전 검증**: 미인증 탐색 캐시는 최대 `64`개·TTL `10초`로 제한하고 동일 HELLO를 병합하며, `PeersChanged`는 `200ms` trailing 디바운스를 적용한다. 눈덩이·빠른 반응·메시지는 UI Dispatcher 적재 전에 `HasFriend`, 타임스탬프, 바운디드 중복/빈도 검사를 통과해야 한다.
- **기능별 요청 제한**: 친구 신청(IP당 `6/분`·전역 `20/분`), 메시지/빠른 반응(`12/10초`), 펫 상호작용(`8/10초`), 게임 이벤트(`40/10초`), 음악 구독 제어(`12/10초`)를 적용하며 정상 30Hz LAN 음악 동기화를 유지한다.

### GCP 중계 서버 방어 (GCP VM · Caddy · Raspberry Pi 경량 호환)
- **HTTP Rate Limiting 및 프록시/HTTPS 정책**: `/api/auth/challenge`·`/api/auth/token`(IP당 `60/분`·전역 `300/분`·동시 `32`), `/health`(IP당 `120/분`·전역 `600/분`)을 적용해 연구실 공유 IP 다중 클라이언트를 수용하면서 폭주를 차단한다. Kestrel은 동시 연결 `600`·요청 본문 `32KB`로 제한하며, `TrustedProxies` 기반(`ForwardLimit = 1`, 비신뢰 프록시/네트워크 차단) 전달 헤더만 신뢰한다. 운영 환경에서는 HTTPS/WSS(`426 HTTPS_REQUIRED`, 로컬 `/health` 제외)를 강제하고 클라이언트는 `AllowInsecureHttp = false` 기본값으로 비루프백 평문 HTTP를 차단한다.
- **SignalR Hub·저장소·캐시 상한**: `SocialHubRateLimitFilter`로 인증 사용자별 `RegisterPresenceAsync`(`12/분`), `UpdatePresenceAsync`(`20/10초`), `SyncKnownFriendsAsync`(`15/분`)를 제한하고, 기능별 메시지(`20/10초`)·상호작용(`12/10초`)·게임(`45/10초`)·친구 신청(`12/분`)을 제한한다. 대기 챌린지(`2,048`, IP당 `64`), 대기 친구 신청(`2,048`, 발신자당 `20`), 신규 등록(`IP당 60/시간`, 전역 `300/시간`), 영속 등록 저장소(`5,000` ID, `25,000` 친구 쌍, `10MB`), 레이트/중복 추적 키(`2,048`) 상한과 `30초` 주기 TTL 정리를 적용한다.
- **원격 음악 단일 대상 라우팅 및 큐 병합**: `MusicFramePacket.TargetPetId`로 해당 서명을 검증할 수 있는 단일 구독자에게만 전달(중복 브로드캐스트 제거)하고, 3계층 빈도 제한(구독자당 `16/초` → 발신자당 `48/초` → 전역 `400/초`)과 시퀀스 역행 폐기·연결당 1-슬롯 병합(`RemoteMusicRelayDispatcher`)으로 송신 큐 적체를 방지한다.
- **단계적 과부하 보호 및 LAN 독립성**: 부하 상승 시 `원격 음악(ShedMusic: 0.75 / 320MB)` → `비친구 탐색(ShedDiscovery: 0.85 / 420MB)` → `신규 연결·등록(ShedNewConnections: 0.95 / 512MB)` 순으로 제한하고, 히스테리시스(`0.10`, `15초` 홀드) 충족 시 1단계씩 자동 복구한다. GCP 장애 또는 보호 모드에서도 LAN P2P 기능은 영향을 받지 않는다.

## 7. 실행 권한, 친구 삭제 동기화, 정산 일관성 및 배포 보안
정의 파일: [app.manifest](../src/LabPet.Client/app.manifest), [FirewallRegistrationService.cs](../src/LabPet.Client/SystemIntegration/FirewallRegistrationService.cs), [TerminalChristmasTreeService.cs](../src/LabPet.Client/SystemIntegration/TerminalChristmasTreeService.cs), [ServerTokenService.cs](../src/LabPet.Server/Security/ServerTokenService.cs), [LabPetTokenAuthenticationHandler.cs](../src/LabPet.Server/Security/LabPetTokenAuthenticationHandler.cs), [RemoteDtoValidator.cs](../src/LabPet.Server/Services/RemoteDtoValidator.cs), [SocialCoordinatorService.cs](../src/LabPet.Client/Social/SocialCoordinatorService.cs), [CoinGamesViewModel.Invites.cs](../src/LabPet.Client/ViewModels/CoinGamesViewModel.Invites.cs), [release.yml](../.github/workflows/release.yml)

- **Windows 최소 권한 및 절대경로 실행**: `LabPet.Client`는 [app.manifest](../src/LabPet.Client/app.manifest)에 `asInvoker`(`uiAccess="false"`)를 명시해 본체를 일반 사용자 권한으로 유지한다. 방화벽 등록·제거·조회는 System32 절대경로(`WindowsPowerShell\v1.0\powershell.exe`, `netsh.exe`)와 명시적 `WorkingDirectory`, `ArgumentList`를 사용하며 `cmd.exe` 호출을 제거했다. 크리스마스트리는 PowerShell `.ps1` 생성·폴백 경로를 제거하고 시스템 `conhost.exe` 또는 `LabPet.Client.exe --christmas-tree` 절대경로(작업 디렉터리 및 `ArgumentList` 명시)와 비-ANSI C# 엔진으로만 실행한다.
- **GCP 인증 · DTO 검증 · 토큰 수명 관리**: `ServerConnectionOptions.AllowInsecureHttp`에 `[JsonIgnore]`를 적용해 `server.json`을 통한 비루프백 `http://` 다운그레이드를 차단한다. 운영 서버(`RequireConfiguredSecret = true`)는 32바이트 미만·고유 문자 10종 미만·약한 플레이스홀더(`changeme`, `replace`, `default`, `example`, `secret123`, `password`, `labpet-dev` 등) 시크릿 시 시작을 거부한다. 인증 핸들러는 `Authorization: Bearer` 헤더만 허용(`?access_token=` 쿼리스트링 차단)하며 클라이언트는 오류 문자열의 `Bearer`·`access_token`을 마스킹(`SanitizeSensitiveText`)하고, `401`·만료 시 캐시 토큰 폐기 및 백그라운드 2분 전 선제 갱신/재연결을 수행한다. [RemoteDtoValidator.cs](../src/LabPet.Server/Services/RemoteDtoValidator.cs)가 HTTP 인증 요청과 Hub DTO(`PetId`, 표시 문자열, 제어문자, 컬렉션 크기, 숫자 범위, 음악 프레임 유한값 `[0f, 10f]`)를 검증하며, 공개 `/health`는 `{ status = "ok", bootId }` 최소 필드만 반환한다.
- **친구 삭제 동기화 · 프라이버시 · 선택적 안전 코드**: [IdentityRegistryStore.cs](../src/LabPet.Server/Storage/IdentityRegistryStore.cs)는 삭제 시 승인 관계·양측 선언 친구·음악 구독([ConnectionPresenceManager.cs](../src/LabPet.Server/Services/ConnectionPresenceManager.cs))을 해제하고 영속 해지 기록(`RevokedFriendships`)을 남겨 과거 친구 목록 재동기화로 삭제 관계가 복원되지 않게 한다. 오프라인 삭제는 `friends.json`의 `RemovedFriendPetIds`에 보관했다가 재접속 시 `RegisterPresenceAsync`로 서버에 반영한다. 비인증 LAN UDP `HELLO` 및 비친구 스냅샷에서는 음악·수면·집중 상태(`IsMusicActive`·`IsSleeping`·`IsFocusing`)를 노출하지 않고 인증된 친구에게만 암호화 제어 패킷으로 전달한다. 친구 수락 시 합의된 비밀키 기반 6자리 확인 코드([PacketCrypto.cs](../src/LabPet.Shared/Protocol/PacketCrypto.cs) `ComputeSafetyCode`, `XXX-XXX`)를 파생·저장해 사용자가 원할 때 대역 외 확인에 활용할 수 있다.
- **경제 정산 일관성 · 롤백 보호 · 배포 파이프라인**: 멀티플레이 예치·정산·복구(`TryReserveMultiplayerWager`·`SettleMultiplayerWagerAsync`·`RecoverInterruptedGameWagers`)에 `GrowthRateMonitor.BeginEconomyChange`를 적용해 정상 누적 보상이 비정상 성장 오탐으로 초기화되지 않게 했으며, 저장·정산 실패 시 코인·예치금을 복원하고 승리·획득 문구 및 긍정 알림을 표시하지 않는다. `ProtectedProgress`에 단조 증가하는 `SnapshotRevision`을 도입해 구버전 스냅샷 덮어쓰기를 차단하되, 봉인 금고(`profile.protection-v1`)에 스냅샷이 없는 구버전 마커 상태에서는 검증된 `.bak` 복구를 유지한다. [verify.yml](../.github/workflows/verify.yml)과 [release.yml](../.github/workflows/release.yml)의 모든 외부 액션은 40자 커밋 SHA로 고정하고 워크플로 루트 권한을 `contents: read`(릴리스 업로드 잡만 `contents: write`)로 제한했으며, `LABPET_SERVER_URL` `https://` 강제, 토큰의 환경변수(`$env:GITHUB_TOKEN`) 전달, `vpk pack` 전 민감/디버그 파일(`.env`, `device_identity.json`, `.pdb`, `.pfx`, `.snk`, `.key`, `Mapping.txt` 등) 검사 차단을 적용했다.
