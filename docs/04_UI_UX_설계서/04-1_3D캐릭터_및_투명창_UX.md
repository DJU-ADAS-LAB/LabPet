# 04-1. 3D 캐릭터 및 투명 창 UX

## 1. 4종 3D 캐릭터 및 5개 커스텀 레이어
구현 파일: [ProceduralPetMeshFactory.cs](../../src/LabPet.Client/Rendering/ProceduralPetMeshFactory.cs), [PetCustomizationCatalog.cs](../../src/LabPet.Client/Rendering/PetCustomizationCatalog.cs)
- **4종 캐릭터**: `mochi_spirit`(말랑 모찌 정령), `chibi_cat`(치비 고양이), `fluffy_cloud`(솜구름), `fluffy_puppy`(솜뭉치 강아지)
- **솜뭉치 강아지**는 둥근 머리와 크림색 주둥이, 부드럽게 처진 귀, 눈과 코의 작은 반사광으로 표현한다. 잠든 표정에서는 입을 다문다.
- **5개 커스텀 레이어**: 캐릭터 종 → 바디/포인트 컬러 → 표정(`default`, `happy`, `sleepy`, `sparkle`) → 머리 소켓 악세서리(`none`, `sprout`, `ribbon`, `headset`, `santa_hat`) → 3D 오라(`none`, `halo_ring`, `music_notes`, `snowflakes`)
- **조명 및 질감**: `AmbientLight` + 따뜻한 키 `DirectionalLight` + 쿨톤 림 `DirectionalLight`와 `DiffuseMaterial` + `SpecularMaterial` + `EmissiveMaterial` 조합

## 2. 투명 펫 창 상호작용 규칙 (`SCR-02`)
구현 파일: [PetWindow.xaml.cs](../../src/LabPet.Client/Views/PetWindow.xaml.cs), [Win32WindowHelper.cs](../../src/LabPet.Client/Interop/Win32WindowHelper.cs)
- **시선 추적(Look-At)**: 전역 마우스 좌표를 펫 중심 기준으로 정규화하여 머리와 몸체를 부드럽게 회전
- **클릭 vs 드래그 판정**: 마우스 다운 후 이동 거리 `5px` 이하는 3D 히트 테스트 기반 쓰다듬기 반응, `5px` 초과는 창 드래그 이동 및 위치 저장
- **빠른 좌우 흔들기**: 드래그 중 0.55초 이내 3회 이상 방향 반전 시 어지러움 3D 반응과 말풍선 표시
- **클릭 투과 집중 모드**: `WS_EX_TRANSPARENT` 토글로 뒤쪽 작업 창에 마우스 클릭 통과(트레이 우클릭 메뉴에서 해제)
- **중복 실행** 시 기존 펫과 트레이를 유지하고 두 번째 실행에 안내를 표시한다. 안내를 닫으면 두 번째 프로세스가 종료된다. [App.xaml.cs](../../src/LabPet.Client/App.xaml.cs)
- **말풍선**은 업데이트와 친구 신청, 최근 메시지 최대 3개를 표시한다. 긴 문장은 줄바꿈하고, 필요한 공간은 펫 위로 늘어난다.
- **이름·레벨 바**와 바로 아래의 **크기·투명도 조절바**는 마우스를 올렸을 때 캐릭터 하단에 함께 표시된다. 캐릭터에서 조절바로 포인터를 옮겨도 조작할 수 있다. [펫 창 XAML](../../src/LabPet.Client/Views/PetWindow.xaml)
- **빠른 메시지**는 말풍선 아이콘을 누른 친구 바로 아래에 펼쳐진다. 전송 후에도 입력창을 유지한다. 같은 아이콘을 다시 누르거나 입력창에서 `Esc`를 누르면 닫힌다. [펫 창 XAML](../../src/LabPet.Client/Views/PetWindow.xaml)
