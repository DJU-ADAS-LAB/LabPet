4. 한쪽 PC에서 음악 재생 중 다른 PC에서 `[노래 따라하기]`를 켜면 3D 펫이 같은 박자로 리듬 애니메이션을 수행하고, 음악을 멈추면 약 1.5~2초 후 자동으로 로컬 모드로 복귀하는지 확인

## 버그 수정: `H.NotifyIcon.Wpf` 트레이 아이콘 `RenderTargetBitmap` 미지원 예외 수정

### 1. 변경 배경

### 2. 수정 파일 및 동작
- [PetWindow.xaml.cs](../../src/LabPet.Client/Views/PetWindow.xaml.cs): `CreateTrayIcon()`이 32x32 PNG를 표준 PNG-in-ICO 컨테이너 바이트로 감싸 `System.Drawing.Icon`을 생성하고 `TrayIcon.Icon`에 직접 할당하도록 변경

### 3. 직접 실행한 빌드·테스트 결과
- `dotnet test LabPet.slnx -c Debug`: 경고 0개, 오류 0개, 15건 통과
- `LabPet.Client.exe` 3초 런타임 기동 스모크 테스트: 크래시 없이 정상 유지 (`AliveAfter3s=True`)

### 4. 사용자 수동 확인 시나리오
1. `dotnet run --project src/LabPet.Client/LabPet.Client.csproj` 실행 시 예외 없이 바탕화면 펫 창이 뜨고 작업 표시줄 시스템 트레이에 핑크 모찌 아이콘이 표시되는지 확인

## 버그 수정: 시스템 오디오 루프백 반응 미동작 원인 수정 (`MMDevice` 조기 해제 및 `WaveFormatExtensible` 누락)

### 1. 변경 배경
실제 음악 재생 시 펫이 반응하지 않는 원인을 점검한 결과, `LoopbackAudioAnalyzer`에서 2가지 원인을 확인했습니다:
1. `TryStartCaptureLocked()`에서 `using var defaultDevice`를 사용해 캡처 시작 직후 `MMDevice` COM 객체가 즉시 해제됨
2. Windows WASAPI 공유 모드 기본 포맷인 `WaveFormatEncoding.Extensible`(32-bit Float / PCM 서브타입) 분기가 누락되어 수신 오디오 패킷이 버려짐

### 2. 수정 파일 및 동작
- [LoopbackAudioAnalyzer.cs](../../src/LabPet.Client/Audio/LoopbackAudioAnalyzer.cs): `_activeDevice` 필드로 `MMDevice` 수명을 캡처 종료 시까지 유지하도록 수정하고, `WaveFormatExtensible`(IEEE Float 32-bit, PCM 16/24/32-bit) 디코딩을 모두 지원하도록 보강

### 3. 직접 실행한 빌드·테스트 결과

## 원형 손잡이와 50~150% 펫 크기 조절

### 1. 변경 배경
- 외형 조절바는 기본 사각형 손잡이와 높이 20 DIP인 두 행을 사용했습니다. 펫 크기 범위는 65~145%였습니다.

### 2. 수정 파일 및 동작
- 크기·투명도 조절바를 가는 트랙과 작은 원형 손잡이로 바꿨습니다. 행 높이를 16 DIP로 줄이고 이름표 아래의 간격과 여백을 좁혔습니다. [펫 창 XAML](../../src/LabPet.Client/Views/PetWindow.xaml)
- 바탕화면 슬라이더와 두 크기 메뉴, 외형 편집의 범위를 50~150%로 맞췄습니다. 화면에 표시하는 펫은 뷰포트 너비에 따라 커지며 창은 조절바와 말풍선이 들어갈 최소 너비를 유지합니다. [펫 창 UI 동작](../../src/LabPet.Client/Views/PetWindow.xaml.cs), [외형 편집 XAML](../../src/LabPet.Client/Views/OnboardingWindow.xaml), [프로필 배율](../../src/LabPet.Shared/Models/PetProfile.cs)

### 3. 직접 실행한 빌드·테스트 결과
- `dotnet build LabPet.slnx -c Debug --disable-build-servers -m:1` 통과. 경고 0개, 오류 0개.
