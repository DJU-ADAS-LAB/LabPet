# 2026-11-21 변경 이력

## 그래픽 품질 고도화: Blender 5.2 캐릭터·액세서리·이펙트 파이프라인, 모션 클립 댄스 및 메모리 최적화

### 1. 변경 배경
기존 절차적 3D 메시(`ProceduralPetMeshFactory`)와 단조로운 사인파 위주 애니메이션의 시각 완성도를 미니멀 3D 피규어·소프트 클레이 감성으로 끌어올리면서, WPF `Viewport3D` 기반 투명 데스크톱 창 호환성과 비그래픽 기능(LAN P2P·코인 게임·오디오 분석·저장소)을 그대로 유지하고 메모리·GPU·유휴 CPU 부하를 최적화했습니다.

### 2. 수정·생성 파일 및 동작
- **Blender 5.2 일체형 소프트 클레이 조형 파이프라인 및 정적 에셋**:

### 4. 사용자 수동 확인 시나리오
1. **기존 실행 중인 Debug 앱 종료 후 새 빌드 실행**: 작업표시줄 시스템 트레이의 LabPet 아이콘에서 `종료`를 누른 뒤 `dotnet run --project src/LabPet.Client/LabPet.Client.csproj -c Release` (또는 `Debug`)로 새로 실행합니다.
2. **4종 클레이 피규어 실루엣·얼굴 밀착 확인**: 온보딩/트레이 `외형 · 이름 변경` 창에서 `fluffy_puppy` → `chibi_cat` → `fluffy_cloud` → `mochi_spirit` 순으로 선택하고 360도 턴테이블로 돌려보며 머리·목·몸통·앞발·뒷발·귀·꼬리가 하나로 이어진 무광 소프트 클레이 피규어 감성과 3/4 측면에서 눈·볼터치가 튀어나오지 않는지 확인합니다.
3. **색상·표정·액세서리 5종·오라 3종 확인**: 바디/포인트 색상 변경 시 즉시 색상만 갱신되는지, `headset` 밴드·`crown`·`sprout`·`santa_hat`·`ribbon`이 정수리에 자연스럽게 밀착되는지 확인합니다.
4. **타이핑·쓰다듬기·리듬 댄스 확인**: 키보드 입력 시 앉은 `fluffy_puppy`와 `chibi_cat` 앞발이 미니 키보드 위로 자연스럽게 올라오는지, 클릭 시 쓰다듬기 별 이펙트, `리듬 댄스 미리보기` 또는 음악 재생 시 춤 전환이 부드러운지 확인합니다.

## 솔로 및 LAN 공동 사다리 게임 공정성·단계 진행·결과 공개·무료 모드 고도화

### 1. 변경 배경
기존 공동 사다리는 참가자 확정 전에 시작 위치를 고를 수 있고(`PendingInviteCount`와 별개로 슬롯 선점), 상품 배치가 `Random.Shared` 기반 정렬이었으며, 애니메이션 시작 전부터 하단 상품·결과 목록·알림·상태 메시지에 결과가 먼저 노출되는 문제가 있었습니다. 이를 초대 응답 → 방장 참가자 확정 → 중복 없는 위치 선택 → CSPRNG Fisher–Yates 셔플 불변 사다리판 → 하단 도착 시 개별 공개 → 0코인 무료/유료 안전 정산·환불 구조로 정비했습니다.

### 4. 사용자 수동 확인 시나리오
1. **솔로 사다리**: `🎮 코인 게임` → `🪜 연구실 사다리`에서 참여자, 상품(`커피 x1, 과자 x1, 통과 x1`), `0코인 (무료)` 또는 유료 참가비를 고르고 `혼자 돌리기`를 누릅니다. 상단에 공개 상품 요약만 표시되고 하단 라벨·결과 목록·상태 줄이 `"?"`/진행 중으로 숨겨진 채 동시 하강하다가 각 줄이 바닥에 도착할 때 해당 상품이 차례로 공개되는지 확인합니다.
2. **LAN 공동 사다리 (무료/유료)**: 방장이 친구를 초대하면 친구의 말풍선과 게임창 배너에 참가비(`무료 (0코인)` 또는 코인)와 전체 상품 요약이 함께 표시되는지, 친구 입장 완료 전/방장 `✔ 참가자 확정` 전에는 시작 번호를 누를 수 없는지 확인합니다.
3. **위치 선택·시작·이탈 환불**: 확정 후 각자 서로 다른 번호를 골라(중복 클릭 불가) 전원 선택이 끝나면 방장이 `▶ 게임 시작`을 눌러 양 PC에 동일한 사다리판이 내려오며 도착 시 결과가 공개되고, 중간 취소·이탈 시 유료 참가비만 1회 정확히 환불되는지 확인합니다.
