## 7. 수면 시 3단 플로팅 `Z Z Z` 방울 애니메이션(`SleepZzzOverlay`) 추가

### 1. 변경 배경
펫이 5분 무입력으로 잠들었을 때 멈춰 있던 정적 `"zzz"` 텍스트 배지 대신, 잠든 느낌을 생동감 있게 전달하도록 머리 위로 `z → Z → Z` 3단 수면 방울이 시차를 두고 살랑거리며 떠올랐다가 사라지는 애니메이션을 추가했습니다.

### 2. 수정·생성 파일 및 동작
- [SleepZzzOverlay.cs](../../src/LabPet.Client/Views/SleepZzzOverlay.cs) (신규):
  - `z`(10.5pt), `Z`(13pt), `Z`(15.5pt) 3개의 캡슐 방울이 0.8초 시차(2.4초 주기)로 떠오르며 커지고 페이드아웃되는 `Storyboard` 애니메이션 컨트롤 구현.
  - `Visibility == Visible`일 때만 애니메이션이 동작하고 `Collapsed`/`Unloaded` 시 즉시 정지해 평상시 CPU/GPU 부하가 발생하지 않도록 구성했으며, 좌상단 배치용 `FlipHorizontal` 옵션을 지원합니다.
- [PetWindow.xaml](../../src/LabPet.Client/Views/PetWindow.xaml), [VisitorPetWindow.xaml](../../src/LabPet.Client/Views/VisitorPetWindow.xaml), `SocialWindow.xaml`:
  - 내 바탕화면 펫, 방문 친구 펫(`FlipHorizontal="True"`), 친구 창 3D 프리뷰에 `SleepZzzOverlay`를 적용했습니다.
- [PetAnimationAndEffectTests.cs](../../tests/LabPet.Tests/PetAnimationAndEffectTests.cs):
  - `SleepZzzOverlay_StartsAndStopsFloatingAnimationWithVisibility` 단위 테스트 추가.

### 4. 사용자 수동 확인 시나리오 (7번 항목)
1. 5분간 입력이 없거나 잠든 친구의 펫을 바탕화면에 데려왔을 때(또는 친구 창 3D 프리뷰에서), 펫 머리 위로 `z → Z → Z` 3단 방울이 차례대로 살랑거리며 떠오르는지 확인합니다.

## 5. GitHub Actions 워크플로 Node.js 24 호환 버전 업그레이드 및 `ObjMeshLoader` 기하 공유 캐시 GC 경합 수정

### 1. 변경 배경
1) GitHub Actions 러너의 Node.js 20 지원 종료(Node.js 24 강제 실행 전환)에 따라 `actions/checkout@v4` 및 `actions/setup-dotnet@v4` 사용 시 출력되던 Node.js 20 사용 중단 경고(deprecation warning)를 제거했습니다.
2) GitHub Actions 병렬 테스트 실행 중 다른 테스트가 `GC.Collect()`를 호출할 때, `ObjMeshLoader._assetCache`의 `WeakReference<ObjMeshAsset>`가 `PetRigHandle`에서 `MeshGeometry3D`만 참조되고 `ObjMeshAsset` 래퍼는 참조되지 않아 조기 수거되면서 두 번째 펫 생성 시 동일 `MeshGeometry3D` 인스턴스 공유 검증(`BuildPetRig_SupportsAllCustomizationsAndReusesSharedFrozenGeometry`)이 간헐적으로 실패하던 원인을 수정했습니다.

### 2. 수정 파일 및 동작
- [release.yml](../../.github/workflows/release.yml), [verify.yml](../../.github/workflows/verify.yml):
  - `actions/checkout@v4` → `actions/checkout@v6` (`runs.using: node24`)
  - `actions/setup-dotnet@v4` → `actions/setup-dotnet@v5` (`runs.using: node24`)
- [ObjMeshLoader.cs](../../src/LabPet.Client/Rendering/ObjMeshLoader.cs):
  - `ConditionalWeakTable<MeshGeometry3D, ObjMeshAsset>`(`_geometryAssetHolders`)를 도입해 장면(`GeometryModel3D`)에서 서브메시 `MeshGeometry3D` 중 하나라도 살아 있는 동안에는 부모 `ObjMeshAsset` 캐시 엔트리가 GC에 조기 수거되지 않도록 수명을 결합하고, 모든 `MeshGeometry3D` 참조가 해제되면 에페메론(Ephemeron) 규칙에 따라 `ObjMeshAsset`도 함께 수거되도록 보장했습니다.
- [BlenderAssetPipelineTests.cs](../../tests/LabPet.Tests/BlenderAssetPipelineTests.cs):
  - 첫 번째 펫과 두 번째 펫 생성 사이에 명시적 `GC.Collect()`를 수행해도 동결된 `MeshGeometry3D` 인스턴스가 그대로 공유되는지 검증하도록 회귀 테스트를 강화했습니다.
- [LabPet.Client.csproj](../../src/LabPet.Client/LabPet.Client.csproj): 패키지 버전을 `0.3.2`로 상향
- **문서 갱신**: [06_배포_자동업데이트_및_방화벽가이드.md](../06_배포_자동업데이트_및_방화벽가이드.md), [08-0_기능명세서_개요.md](../08_기능명세서/08-0_기능명세서_개요.md), [08-4_배포_업데이트_운영.md](../08_기능명세서/08-4_배포_업데이트_운영.md)

`LabPet.Client`(`OutputType=WinExe`, 콘솔이 없는 GUI 프로세스)에서 `TerminalChristmasTreeService`가 `conhost.exe`를 `UseShellExecute = false`로 호출하면 `conhost.exe`가 새 창을 생성하지 않고 즉시 종료코드 `0`으로 종료되어 우클릭 메뉴에서 크리스마스 트리가 뜨지 않는 문제가 있었습니다.

### 2. 수정 파일 및 동작
- [TerminalChristmasTreeService.cs](../../src/LabPet.Client/SystemIntegration/TerminalChristmasTreeService.cs):
  - Windows `CommandLineToArgvW` 규칙에 맞게 따옴표·역슬래시를 이스케이프하는 `QuoteCommandLineArgument()` 추가.
  - `BuildLaunchStartInfo()`가 `UseShellExecute = true`, `WindowStyle = ProcessWindowStyle.Normal`로 `conhost.exe`(폴백: `powershell.exe`)를 실행하도록 수정.
  - `Launch()`에서 `conhost.exe` 실행 후 `!proc.WaitForExit(150)`을 확인해 150ms 이내 즉시 종료 시 `powershell.exe` 단독 창으로 자동 폴백하도록 보강.
- [TerminalChristmasTreeTests.cs](../../tests/LabPet.Tests/TerminalChristmasTreeTests.cs): `UseShellExecute = true`·`WindowStyle = Normal`·`QuoteCommandLineArgument` 이스케이프 회귀 테스트 갱신 및 추가.

### 3. 직접 실행한 빌드·테스트 결과 (4번 항목 기준)
- **전체 Release 빌드**: `dotnet build LabPet.slnx -c Release -v minimal` → 경고 0개, 오류 0개

- **제외 범위**: 실행 중인 `LabPet.Client` (`v0.3.0`, PID `29212`) 보호를 위해 `Debug` 빌드는 실행하지 않았습니다.

### 4. 사용자 수동 확인 시나리오 (4번 항목)
