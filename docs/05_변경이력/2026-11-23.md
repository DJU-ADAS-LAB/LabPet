## 5. GitHub Actions 워크플로 Node.js 24 호환 버전(`actions/checkout@v6`, `actions/setup-dotnet@v5`) 업그레이드

### 1. 변경 배경
GitHub Actions 러너의 Node.js 20 지원 종료(Node.js 24 강제 실행 전환)에 따라 `actions/checkout@v4` 및 `actions/setup-dotnet@v4` 사용 시 출력되던 Node.js 20 사용 중단 경고(deprecation warning)를 제거했습니다.

### 2. 수정 파일 및 동작
- [release.yml](../../.github/workflows/release.yml), [verify.yml](../../.github/workflows/verify.yml):

  - `actions/setup-dotnet@v4` → `actions/setup-dotnet@v5` (`runs.using: node24`)
- [LabPet.Client.csproj](../../src/LabPet.Client/LabPet.Client.csproj): 패키지 버전을 `0.3.2`로 상향
- **문서 갱신**: [06_배포_자동업데이트_및_방화벽가이드.md](../06_배포_자동업데이트_및_방화벽가이드.md), [08-0_기능명세서_개요.md](../08_기능명세서/08-0_기능명세서_개요.md), [08-4_배포_업데이트_운영.md](../08_기능명세서/08-4_배포_업데이트_운영.md)

## 4. 크리스마스 트리 `WinExe` 창 미표시 버그 수정

### 1. 변경 배경
`LabPet.Client`(`OutputType=WinExe`, 콘솔이 없는 GUI 프로세스)에서 `TerminalChristmasTreeService`가 `conhost.exe`를 `UseShellExecute = false`로 호출하면 `conhost.exe`가 새 창을 생성하지 않고 즉시 종료코드 `0`으로 종료되어 우클릭 메뉴에서 크리스마스 트리가 뜨지 않는 문제가 있었습니다.

### 2. 수정 파일 및 동작
- [TerminalChristmasTreeService.cs](../../src/LabPet.Client/SystemIntegration/TerminalChristmasTreeService.cs):
  - Windows `CommandLineToArgvW` 규칙에 맞게 따옴표·역슬래시를 이스케이프하는 `QuoteCommandLineArgument()` 추가.
  - `BuildLaunchStartInfo()`가 `UseShellExecute = true`, `WindowStyle = ProcessWindowStyle.Normal`로 `conhost.exe`(폴백: `powershell.exe`)를 실행하도록 수정.
  - `Launch()`에서 `conhost.exe` 실행 후 `!proc.WaitForExit(150)`을 확인해 150ms 이내 즉시 종료 시 `powershell.exe` 단독 창으로 자동 폴백하도록 보강.
- [TerminalChristmasTreeTests.cs](../../tests/LabPet.Tests/TerminalChristmasTreeTests.cs): `UseShellExecute = true`·`WindowStyle = Normal`·`QuoteCommandLineArgument` 이스케이프 회귀 테스트 갱신 및 추가.

### 3. 직접 실행한 빌드·테스트 결과 (4번 항목 기준)
- **전체 Release 빌드**: `dotnet build LabPet.slnx -c Release -v minimal` → 경고 0개, 오류 0개
- **전체 Release 테스트**: `dotnet test LabPet.slnx -c Release --no-build --verbosity minimal` → `LabPet.Tests` **116건 실행 / 116건 통과** (실패 0건, 건너뜀 0건, 5초)
- **WinExe 창 생성 실검증**: `FreeConsole()`로 부모 콘솔을 제거한 프로세스에서 수정 방식(`UseShellExecute = true`, `WindowStyle = Normal`)으로 `conhost.exe` 실행 시 `HasExited=False`, `MainWindowHandle=16517540` 정상 창 생성 확인(확인 후 테스트 프로세스 종료).
- **제외 범위**: 실행 중인 `LabPet.Client` (`v0.3.0`, PID `29212`) 보호를 위해 `Debug` 빌드는 실행하지 않았습니다.

### 4. 사용자 수동 확인 시나리오 (4번 항목)
1. 설치된 `v0.3.0` (`AppData\Local\LabPet\current\LabPet.Client.exe`)은 수정 전 빌드이므로, 기존 `LabPet.Client`를 트레이에서 종료한 뒤 저장소의 `dotnet run --project src\LabPet.Client\LabPet.Client.csproj -c Release --no-build`로 실행합니다.
2. 펫 또는 트레이 우클릭 메뉴에서 **`🎄 크리스마스 트리`** 를 클릭해 독립 콘솔 창이 바로 뜨고 키 입력(`Space`/`F`/`S`/`Q`)이 동작하는지 확인합니다.

2. **우클릭·트레이 메뉴 확인**: 바탕화면 펫과 트레이 아이콘을 각각 우클릭해 `🎯  클릭 투과 집중 모드` 아이콘 정렬 및 `🎄  크리스마스 트리` 메뉴명을 확인합니다.
3. **고밀도 애니메이션 체감 속도 확인**: `🎄  크리스마스 트리` 클릭 시 열리는 창(`180×56`, `9px` 소형 폰트)에서 오로라·눈송이·불꽃놀이·얼음 연못 수면 반사·오두막·눈사람·트리가 지연 없이 부드럽게 재생되는지 확인합니다.
4. **키보드 조작 확인**: `Space`(조명 4모드), `F`(폭죽 발사), `S`(눈 세기 3단계), `Q`/`Esc`/`Ctrl+C`(종료 및 복구) 동작을 확인합니다.
