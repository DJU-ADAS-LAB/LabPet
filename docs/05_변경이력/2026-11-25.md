  3. 그 뒤 친구 채팅 메시지가 도착하면 `LayoutBubblePopup()`이 `VisitorBubblePopup.IsOpen == false`인 상태에서 `VisitorBubbleContent.InvalidateMeasure(); VisitorBubbleContent.Measure(Infinity);`를 먼저 실행했습니다. 이 때문에 `VisitorBubbleContent.DesiredSize`에는 이전 상태 문구(`"놀러 왔어!"`)의 크기(`72×27`)만 남아 있고, 새로 추가된 채팅 카드 `Border`는 미측정 상태(`DesiredSize = 0×0`)로 남았습니다.
  4. 이어서 `GetNearestCardBounds`가 `(card.DesiredSize.Height - 4) * scaleY < 0`인 음수 높이로 `new Rect(x, y, width, height)`를 생성하면서 처리되지 않은 `ArgumentException`이 WPF `Dispatcher`로 전파되어 프로세스 전체가 종료되었습니다.
- **동반 결함**:
  - `DockPanel`만 `InvalidateMeasure()`해 자식 카드 텍스트 변경 시 이전 측정 캐시가 남는 문제, `IsBelowHead` 반전 재측정 후 `natural`·`placement` 미갱신, `Rect.Intersect` 빈 결과(`Rect.Empty`, `-Infinity`), `Math.Clamp` 경계 역전 및 `NaN`/`Infinity` 미방어, `PresentationSource` 미연결 상태 `PointToScreen` 호출 가능성, 백그라운드 만료와 `Items` 동시 접근, frozen `TranslateTransform` 수정 가능성, Win32 HWND(`IsWindow`)·`HwndSource.IsDisposed` 미검증, `Dispatcher` 예외 격리 및 로컬 크래시 로그 부재를 함께 해결했습니다.

## 0.3.15 로컬 성장 상태 보호 및 1회 이전

- 변경 배경 — 설치된 앱의 프로필을 편집해 코인과 레벨을 바꾸는 경로를 차단한다. 사용자가 지정한 초기화는 0.3.15 평문 성장 상태 최초 이전 시 레벨 50 초과와 코인 100,000 초과가 모두 성립하는 경우에 적용한다.
- 수정 동작 — [프로필 저장소](../../src/LabPet.Client/Storage/JsonAppDataStore.cs)는 성장 상태와 펫 ID를 DPAPI로 보호해 외형과 같은 원자적 스냅샷에 저장한다. 대상 프로필은 레벨 1·코인 0으로 이전하고 미정산 참가비와 진행 중 솔로 사다리를 정리한다. 손상된 원본은 검증된 백업과 분리해 보존하며 두 파일을 모두 검증할 수 없으면 [시작 시 복구 안내](../../src/LabPet.Client/App.xaml.cs)를 표시한다.
- 직접 실행한 검증 — `dotnet restore LabPet.slnx --force -v:q`, `dotnet build LabPet.slnx -c Release --no-restore -m:1 -v:q`, `dotnet test LabPet.slnx -c Release --no-build --no-restore --blame-hang-timeout 60s`. 빌드 경고·오류 0개, 전체 376개 통과. [회귀 테스트](../../tests/LabPet.Tests/StorageAndMigratorTests.cs)에서 두 임계값, 보호 이후 재실행, 0.3.15 건너뛴 버전, 평문 추가 및 스키마 하향, 백업 복구와 평문 롤백 거부를 검증했다. 설치된 앱 데이터·공개 배포·실기기 다른 Windows 계정 복원은 미실행이다.
- 수동 확인 — 별도 Windows 테스트 계정에서 0.3.14 프로필을 준비한 뒤 0.3.15로 업데이트한다. 레벨 51·100,001코인은 레벨 1·0코인으로, 레벨 50 또는 정확히 100,000코인인 프로필은 기존 값으로 열리는지 확인한다. 보호된 파일이 모두 손상된 경우 파일을 보존하고 복구 안내를 표시하는지 확인한다.
