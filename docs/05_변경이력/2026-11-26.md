# 2026-11-26 변경 이력

## 최종 보안 취약점 개선 (Windows 실행 · GCP 인증 · 친구 삭제 · 정산 · 배포)

- 변경 배경 — 기존 LAN·GCP DoS 방어 작업과 중복되거나 충돌하지 않도록 구조를 유지하면서, Windows 프로세스/경로 실행 보안, GCP 인증 토큰·시크릿·DTO 검증, 양측/오프라인 친구 삭제 동기화 및 프라이버시 보호, 멀티플레이 정산·스냅샷 롤백 방어, GitHub Actions 배포 파이프라인 무결성을 보강했다.

## LAN P2P 및 GCP 중계 DoS 방어 강화

- 변경 배경 — 외부 유료 인프라(Cloud Armor, 유료 로드밸런서, Redis 등) 없이 기존 GCP VM + Caddy 및 LAN P2P 구조(Raspberry Pi 호환 포함)를 유지하면서, 비정상 패킷·연결·요청 폭주 및 메모리/저장소 무한 증가를 방어하고 연구실 공유 IP 환경과 30Hz LAN 음악 동기화를 보호하도록 클라이언트와 서버를 보강했다.
- 수정 파일 및 동작 —
  - LAN P2P 방어([LanDosProtectionOptions.cs](../../src/LabPet.Client/Network/LanDosProtectionOptions.cs), [BoundedRateLimiter.cs](../../src/LabPet.Client/Network/BoundedRateLimiter.cs), [LanP2pTransport.cs](../../src/LabPet.Client/Network/LanP2pTransport.cs), [LanP2pTransport.Control.cs](../../src/LabPet.Client/Network/LanP2pTransport.Control.cs), [LanP2pTransport.Presence.cs](../../src/LabPet.Client/Network/LanP2pTransport.Presence.cs)):
    - 역직렬화 이전 UDP/TCP 크기 제한(탐색 UDP `4,096B`, 음악 UDP `1,024B`, 제어 TCP `16KB`)과 IP별→전역 슬라이딩 윈도우 빈도 제한(구체 제한 선행 평가로 단일 IP의 전역 쿼터 소진 방지)을 적용했다.
    - TCP 제어 동시 연결(`16`개) 중 `8`개를 인증된 친구 IP 전용으로 예약해 비친구 연결(`IP당 최대 3`, 총 비친구 `8`)이 포화되어도 친구 제어가 유지되도록 분리했다.
    - 미인증 탐색 캐시 상한(`64`개) 및 TTL(`10초`), 동일 HELLO 병합, `PeersChanged` trailing 디바운스(`200ms`), 기능별 수신 제한(친구 요청·메시지·상호작용·게임 이벤트·음악 제어)을 적용했다.
  - 클라이언트 Dispatcher 전 차단 및 HTTPS 보호([HybridTransportRouter.cs](../../src/LabPet.Client/Network/HybridTransportRouter.cs), [SocialCoordinatorService.cs](../../src/LabPet.Client/Social/SocialCoordinatorService.cs), [SnowballInteractionService.cs](../../src/LabPet.Client/Social/SnowballInteractionService.cs), [App.xaml.cs](../../src/LabPet.Client/App.xaml.cs), [ServerConnectionOptions.cs](../../src/LabPet.Client/Network/ServerConnectionOptions.cs)):
    - 눈덩이(`SnowballInteractionService.OnReceived`) 및 메시지 수신 시 Dispatcher 큐에 적재하기 전 친구 확인(`HasFriend`)·타임스탬프·바운디드 중복/빈도 검사를 수행하고 상태 갱신 알림을 병합하도록 보강했다(기존 Obfuscar 매핑 대상 메서드 시그니처·특성 유지).
    - `ServerConnectionOptions.AllowInsecureHttp`(기본 `false`)로 비루프백 평문 `http://` 원격 연결을 차단했다.
  - GCP/Raspberry Pi 서버 방어([ServerOptions.cs](../../src/LabPet.Server/Options/ServerOptions.cs), [LabPetServerHost.cs](../../src/LabPet.Server/LabPetServerHost.cs), [SocialHubRateLimitFilter.cs](../../src/LabPet.Server/Hubs/SocialHubRateLimitFilter.cs), [SocialHub.cs](../../src/LabPet.Server/Hubs/SocialHub.cs), [RateLimiterAndDedupService.cs](../../src/LabPet.Server/Services/RateLimiterAndDedupService.cs), [RemoteMusicRelayDispatcher.cs](../../src/LabPet.Server/Services/RemoteMusicRelayDispatcher.cs), [ServerOverloadProtectionService.cs](../../src/LabPet.Server/Services/ServerOverloadProtectionService.cs), [AuthChallengeStore.cs](../../src/LabPet.Server/Security/AuthChallengeStore.cs), [PendingFriendRequestStore.cs](../../src/LabPet.Server/Services/PendingFriendRequestStore.cs), [IdentityRegistryStore.cs](../../src/LabPet.Server/Storage/IdentityRegistryStore.cs), [ConnectionPresenceManager.cs](../../src/LabPet.Server/Services/ConnectionPresenceManager.cs), [ThrottledLogService.cs](../../src/LabPet.Server/Services/ThrottledLogService.cs), [BackgroundCleanupService.cs](../../src/LabPet.Server/Services/BackgroundCleanupService.cs), [Packets.cs](../../src/LabPet.Shared/Protocol/Packets.cs), [GcpSignalRTransport.cs](../../src/LabPet.Client/Network/GcpSignalRTransport.cs)):

    - `SocialHubRateLimitFilter` 및 `RateLimiterAndDedupService`로 인증 사용자·메서드·기능별 빈도 제한과 바운디드 버킷/TTL 정리(`CleanupIntervalSeconds = 30`), `IdentityRegistryStore`(`MaxRegisteredIdentities = 5,000`, `MaxApprovedFriendships = 25,000`, `MaxRegistryFileBytes = 10MB`)·`PendingFriendRequestStore`(`2,048`, 발신자당 `20`)·`AuthChallengeStore`(`2,048`, IP당 `64`) 상한을 적용했다.
    - `MusicFramePacket.TargetPetId` 및 `RemoteMusicRelayDispatcher`로 해당 서명을 검증할 수 있는 단일 구독자에게만 전달해 중복 브로드캐스트를 제거하고, 3계층 빈도 제한(구독자→발신자→전역)·구버전 시퀀스 폐기·연결당 1-슬롯 병합을 구현했다.

  - 회귀 테스트 및 명세([LanDosProtectionTests.cs](../../tests/LabPet.Tests/LanDosProtectionTests.cs), [GcpDosProtectionTests.cs](../../tests/LabPet.Tests/GcpDosProtectionTests.cs), [03_네트워크_프로토콜_및_보안명세.md](../03_네트워크_프로토콜_및_보안명세.md)):
