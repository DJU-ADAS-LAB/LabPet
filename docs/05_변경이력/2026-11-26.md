# 2026-11-26 변경 이력

## 크리스마스트리 3D ASCII 렌더링 엔진 개편 및 시각·호환성 고도화

- 변경 배경 — 중단되어 있던 3D 터미널 크리스마스트리 개편 작업을 이어받아 완료하고, 2열 한글 문자 기반 렌더러를 1열 고밀도 7비트 ASCII 기반 3D 렌더러로 전환해 가로 해상도·글꼴 종횡비 정합성·명암·입체감·파티클 완성도를 높였다.
- 수정 파일 및 동작 —
  - 3D 렌더링 코어([AsciiDepthSurface.cs](../../src/LabPet.Client/Rendering/Terminal3D/AsciiDepthSurface.cs), [AsciiAnsiFrameWriter.cs](../../src/LabPet.Client/Rendering/Terminal3D/AsciiAnsiFrameWriter.cs), [TerminalPointProjector.cs](../../src/LabPet.Client/Rendering/Terminal3D/TerminalPointProjector.cs)): 기존 `HangulDepthSurface.cs`·`HangulAnsiFrameWriter.cs`를 제거하고, 1열 7비트 ASCII 밀도 램프(`.,':;-~=+!*ox#%&$@`), Z-Buffer 깊이 판정 및 가산 발광 블렌딩(`TryBlendGlow`), Blinn-Phong 반사광·프레넬 림 라이트·트리 코어 전구광·거리 감쇠·후면 제거(Back-face culling), ANSI True Color 차분 출력과 단일 버퍼 HUD 조합을 구현했다.
  - 3D 장면·파티클([ChristmasTreeGeometry.cs](../../src/LabPet.Client/Rendering/Terminal3D/ChristmasTreeGeometry.cs), [ChristmasTreeScene.cs](../../src/LabPet.Client/Rendering/Terminal3D/ChristmasTreeScene.cs), [ChristmasParticleField.cs](../../src/LabPet.Client/Rendering/Terminal3D/ChristmasParticleField.cs)): 계단형 오버행 처마와 하단 음영이 뚜렷한 6단 풍성한 소나무 가지(민트-에메랄드-송엽색 및 재질별 전용 ASCII 램프), 선물 상자와 대비되는 어두운 밤눈 원형 3D 지면, 트리 전면을 사선으로 가로지르는 5회전 황금 가랜드와 요정 전구, 34개 보석 오너먼트, 좌·중·우 균형 배치된 6개 리본 선물 상자(보라·빨강·청록·파랑), 어느 회전 각도에서도 넓은 5각 실루엣을 유지하는 직교 이중 3D 황금 별과 은은한 잔광, 밤하늘 96개 반짝이는 별빛, 깊이별 ASCII 눈송이(`*`/`+`/`o`/`:`/`.`), 상승 꼬리와 2중 폭발·잔광 궤적을 가진 다단계 불꽃놀이, 4종 조명 모드와 `0~1 / 1~3 / 3~4 / 4~5 / 5+` 등장 타임라인을 구현했다.
  - 실행 루프 및 호환성([ChristmasTreeConsoleRunner.cs](../../src/LabPet.Client/SystemIntegration/ChristmasTreeConsoleRunner.cs), [ChristmasConsoleState.cs](../../src/LabPet.Client/SystemIntegration/ChristmasConsoleState.cs), [ChristmasTreeStartup.cs](../../src/LabPet.Client/SystemIntegration/ChristmasTreeStartup.cs), [ChristmasTreeInstance.cs](../../src/LabPet.Client/SystemIntegration/ChristmasTreeInstance.cs), [TerminalChristmasTreeService.cs](../../src/LabPet.Client/SystemIntegration/TerminalChristmasTreeService.cs), [TerminalChristmasTreeEngine.cs](../../src/LabPet.Client/SystemIntegration/TerminalChristmasTreeEngine.cs)): 1열 ASCII 셀 종횡비(`fontWidth / fontHeight`, 폴백 `0.5f`), 단일 버퍼 프레임+HUD 원자 출력, 적응형 샘플 스트라이드 및 30~60FPS 페이싱, 최소화 시 렌더링 중단·복원 재그리기, `ArgumentList` 직접 실행(메타문자 보호), 첫 프레임 출력 완료 신호(`Ready`/`Failed`) 및 안전한 폴백 분기(`CanFallback`), 기존 PowerShell/비-ANSI 호환 폴백 보존을 반영했다.
  - 회귀 테스트 및 명세([Terminal3DCoreTests.cs](../../tests/LabPet.Tests/Terminal3DCoreTests.cs), [ChristmasTreeSceneTests.cs](../../tests/LabPet.Tests/ChristmasTreeSceneTests.cs), [ChristmasTreeStartupTests.cs](../../tests/LabPet.Tests/ChristmasTreeStartupTests.cs), [TerminalChristmasTreeTests.cs](../../tests/LabPet.Tests/TerminalChristmasTreeTests.cs), [08-1_코어3D_온보딩_저장소.md](../08_기능명세서/08-1_코어3D_온보딩_저장소.md)): 1열 ASCII 깊이·가산 발광·차분 출력·타임라인·조명 모드·시작 신호·셸 메타문자 안전성 테스트와 기능명세를 갱신했다.

  - `Release` 빌드 및 전체 테스트: `dotnet build LabPet.slnx -c Release --no-restore -v:q` 경고 0·오류 0, `dotnet test LabPet.slnx -c Release --no-build --no-restore --blame-hang-timeout 60s --nologo` 전체 **438건 통과** (실패 0, 건너뜀 0)
  - 난독화 배포 DLL 검증: 임시 폴더 `win-x64` self-contained 게시 → [Protect-LabPetRelease.ps1](../../tools/obfuscation/Protect-LabPetRelease.ps1) 난독화·매핑 검증 통과 → 난독화된 `LabPet.Client.dll`로 크리스마스트리 관련 테스트 **30건 통과** (실패 0, 건너뜀 0)

  - **미실행 범위**: 실제 `Setup.exe` 설치본·`Portable.zip`·Velopack 차분 업데이트 직후 테스트, .NET 런타임 미설치 별도 PC 검증, Windows Terminal과 클래식 콘솔 호스트 각각의 수동 키 입력·리사이즈·최소화/복원 확인, 30분 연속 실행 메모리 모니터링
- 사용자 수동 확인 시나리오 —
  1. `LabPet` 우클릭 또는 트레이 메뉴에서 `🎄 크리스마스 트리`를 실행해 검은 배경 위에 `0~1초`(눈+원형 지면) → `1~3초`(6단 층진 3D ASCII 트리 성장) → `3~4초`(황금 가랜드·6개 리본 선물) → `4~5초`(오너먼트 점등·회전 시작) → `5초`(꼭대기 5각 별·황금 광선 점등) → `5초 이후`(무한 회전·눈·불꽃놀이)가 순서대로 재생되는지 확인한다.
  2. `Space`(회전 토글), `←/→`(회전 방향·속도), `↑/↓`(확대·축소), `S`(눈 강도), `L`(조명 4모드), `F`(불꽃놀이), `R`(초기 등장 재시작), `F11`(최대화 전환), `Q`/`ESC`(종료 및 본체 정상 유지)가 부드럽게 반응하는지 확인한다.
  3. 창 크기를 조절하거나 최소화 후 복원했을 때 깨짐·잔상 없이 중앙 정렬로 다시 그려지고, 트리 실행 중 다시 `🎄 크리스마스 트리`를 눌렀을 때 새 창이 중복 생성되지 않고 기존 창이 활성화되는지 확인한다.

## v0.3.17 릴리스 준비 및 1회 성장 초기화 조건(`레벨 > 50 || 코인 > 50,000`) 반영

- 변경 배경 — 3D 액세서리·오라 확장, 성장률 감사·호스트 가드, 컴팩트 오버레이, 3D ASCII 크리스마스트리 개편 사항을 `v0.3.17`로 배포하면서, 기존 `0.3.16` 1회 초기화 조건(`레벨 > 50 && 코인 >= 50,000`)을 사용자 요청에 따라 `0.3.17` 1회 초기화 및 OR 조건(`레벨 > 50 || 코인 > 50,000`)으로 갱신했다.
- 수정 파일 및 동작 —
  - [LabPet.Client.csproj](../../src/LabPet.Client/LabPet.Client.csproj): `<Version>`을 `0.3.17`로 상향했다.
  - [JsonAppDataStore.cs](../../src/LabPet.Client/Storage/JsonAppDataStore.cs): `MigrationResetRelease`를 `"0.3.17"`로 변경하고 `ApplyGrowthReset` 초기화 판정을 `progress.Level > MigrationResetLevel || progress.Coins > MigrationResetCoins`로 수정했다. `0.3.17` 첫 로드 시 조건에 해당하면 레벨·XP·코인 및 대기 보상을 1회 초기화하고 DPAPI 보호 영역에 `0.3.17` 영수증을 기록해 이후 재실행에서는 다시 초기화되지 않도록 유지한다.
  - 회귀 테스트([StorageAndMigratorTests.cs](../../tests/LabPet.Tests/StorageAndMigratorTests.cs), [GrowthRateMonitorTests.cs](../../tests/LabPet.Tests/GrowthRateMonitorTests.cs), [TerminalChristmasTreeTests.cs](../../tests/LabPet.Tests/TerminalChristmasTreeTests.cs), [UpgradeAndUpdateTests.cs](../../tests/LabPet.Tests/UpgradeAndUpdateTests.cs), [GameUiUxAndInviteTests.cs](../../tests/LabPet.Tests/GameUiUxAndInviteTests.cs)): `0.3.17` 1회 초기화 OR 경계 케이스(`(50, 50000)` 유지 / `(51, 50000)`·`(50, 50001)`·`(51, 50001)` 초기화), 호스트 가드 분리 생성자 호출, 2줄 컴팩트 오버레이 표시 검증을 최신 동작에 맞게 정비했다.
- 직접 실행한 빌드·테스트 결과 —
  - `dotnet build LabPet.slnx -c Release --no-restore -v minimal`: 경고 0, 오류 0
  - `dotnet test LabPet.slnx -c Release --no-build --no-restore --blame-hang-timeout 60s --verbosity minimal`: 전체 **495건 통과** (실패 0, 건너뜀 0)
  - **미실행 범위**: 실제 사용자 PC에서 `0.3.16 → 0.3.17` Velopack 자동 업데이트 수동 적용 확인
- 사용자 수동 확인 시나리오 —
  1. `v0.3.16` 이하 설치본에서 `v0.3.17`로 업데이트 후 앱을 실행했을 때, 레벨이 `50` 초과이거나 코인이 `50,000` 초과인 프로필만 레벨 `1`·코인 `0`으로 1회 초기화되고, 경계값(`레벨 50 / 코인 50,000`) 이하 프로필은 유지되는지 확인한다.
  2. 초기화 이후 코인·레벨을 다시 올리고 앱을 재실행했을 때 반복 초기화되지 않고 정상 유지되는지 확인한다.
  3. 3D 액세서리·오라, 컴팩트 친구 오버레이 2줄 표기, `🎄 크리스마스 트리` 실행이 정상 동작하는지 확인한다.
