# 06. 배포 · 자동 업데이트 · 방화벽 및 SmartScreen 가이드

## 1. Velopack 클라이언트 진입점 및 차분 업데이트
- **수동 진입점**: [Program.cs](../src/LabPet.Client/Program.cs) 최상단에서 `VelopackApp.Build().Run()`을 호출해 설치/업데이트/제거 훅이 WPF 초기화보다 먼저 실행되도록 구성했습니다.
- **업데이트 주기 및 동작**: [UpdateService.cs](../src/LabPet.Client/Updates/UpdateService.cs)는 앱 시작 8초 후(실패 시 20초 후 재시도), 이후 5분 주기 폴링, LAN 피어로부터 상위 `appVersion`이 감지될 때(2분 쿨다운), 또는 펫 우클릭·트레이 메뉴 `업데이트 확인` 클릭 시 차분(`.nupkg`) 업데이트를 백그라운드 다운로드합니다. Windows 부팅 자동 실행(`--autostart`) 시에는 무인으로 즉시 재시작 적용하며, 일반 실행 중에는 펫 위 말풍선(`[업데이트 / 나중에]`)으로 안내합니다.
- **기본 피드 및 소스 교체**: [UpdateSourceOptions.cs](../src/LabPet.Client/Updates/UpdateSourceOptions.cs)는 GitHub REST API 속도 제한(60회/시간)을 우회하기 위해 기본적으로 `SimpleWebSource`(`https://github.com/DJU-ADAS-LAB/LabPet/releases/latest/download`)를 사용하며, 향후 `SimpleWebFeedUrl`만 GCP Cloud Storage 정적 버킷 URL로 바꾸면 무중단 이전이 가능합니다.

## 2. GitHub Actions 자동 릴리스 파이프라인
워크플로 파일: [.github/workflows/release.yml](../.github/workflows/release.yml)
1. `v*.*.*` 형식의 태그 푸시 (예: `git tag v0.1.0 && git push origin v0.1.0`)
2. `windows-latest` 러너에서 `dotnet test LabPet.slnx -c Release` 및 `dotnet publish -r win-x64 --self-contained true` 실행
3. NuGet 패키지와 동일 버전(`1.2.161`)의 `vpk` CLI 설치
4. `vpk download github`로 직전 릴리스 다운로드(최초 릴리스 실패 무시) → `vpk pack`으로 `Setup.exe`, `full.nupkg`, `delta.nupkg`, `releases.win.json` 생성 → `vpk upload github --publish`로 정식 릴리스 게시
5. 실제 배포 전 [UpdateSourceOptions.cs](../src/LabPet.Client/Updates/UpdateSourceOptions.cs)의 `GitHubRepoUrl`을 실제 저장소 URL로 변경해 주세요.

## 3. Windows 시작 프로그램 자동 실행
- 구현 파일: [StartupRegistrationService.cs](../src/LabPet.Client/SystemIntegration/StartupRegistrationService.cs)
- `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`에 `Environment.ProcessPath`를 등록합니다. Velopack 설치 환경에서는 고정 경로 `%LocalAppData%\LabPet\current\LabPet.Client.exe`가 등록되므로 업데이트 이후에도 자동 실행이 유지됩니다.

## 4. Windows 방화벽 및 SmartScreen 안내
- **방화벽 (모든 네트워크 프로필 `Any` · 로컬 서브넷 `LocalSubnet` · LabPet 실행 파일 제한 인바운드 허용 및 설치 시 자동 등록)**:
  - UDP `45678` (LAN 자동 탐색)
  - UDP `45679` (노래 따라하기 30Hz 오디오 프레임)
  - TCP `45680` (친구 신청/수락, 말풍선 메시지, 노래 따라하기 구독 제어, 친구 코인 게임 이벤트)
  - 보안 강화를 위해 원격 주소를 같은 로컬 서브넷(`remoteip=localsubnet` / `-RemoteAddress LocalSubnet`)으로 제한하고, 현재 `LabPet.Client.exe` 실행 파일 경로(`program=...` / `-Program ...`)에만 포트를 개방합니다.
  - 설치 시 [FirewallRegistrationService.cs](../src/LabPet.Client/SystemIntegration/FirewallRegistrationService.cs)가 자동 등록을 시도하며, 앱 트레이 메뉴 `방화벽 · 네트워크 안내`([EnvironmentGuideWindow.xaml](../src/LabPet.Client/Views/EnvironmentGuideWindow.xaml))에서 UDP·TCP 규칙 존재 여부와 보안 강화 조건 적용 상태를 확인하고 원클릭 재등록 또는 관리자 PowerShell 명령 복사를 수행할 수 있습니다.
- **SmartScreen**: 코드 서명 인증서가 없는 초기 배포판 실행 시 Windows Defender SmartScreen 파란 경고 화면이 표시되면 **`추가 정보` → `실행`**을 선택해 설치합니다.
