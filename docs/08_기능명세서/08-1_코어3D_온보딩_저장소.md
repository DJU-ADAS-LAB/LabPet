# 08-1. 코어 3D · 온보딩 · 분리 저장소 기능명세

## FT-01: 공용 프로토콜·모델·`ISocialTransport`
- **구현 파일**: [ProtocolConstants.cs](../../src/LabPet.Shared/Protocol/ProtocolConstants.cs), [ProtocolJson.cs](../../src/LabPet.Shared/Protocol/ProtocolJson.cs), [Packets.cs](../../src/LabPet.Shared/Protocol/Packets.cs), [PacketSigner.cs](../../src/LabPet.Shared/Protocol/PacketSigner.cs), [ISocialTransport.cs](../../src/LabPet.Shared/Transport/ISocialTransport.cs)
- **동작 규칙**: 프로토콜 버전 호환성 판정(`Compatible` / `PeerOutdated` / `LocalOutdated`), 미지원 JSON 필드 무시, HMAC-SHA256 상수 시간 검증을 제공한다.

## FT-02: 절차적 3D 캐릭터 4종 및 커스텀 레이어
- **솜뭉치 강아지**는 펼쳐진 귀 안쪽, 두 볼의 크림색 주둥이, 코 반사광과 표정별 입 모양을 사용한다. [메시 검증](../../tests/LabPet.Tests/MeshFactoryTests.cs)
- **메시 공유**는 정점·법선·인덱스가 같은 경우에만 적용한다. 색이나 애니메이션 변경은 해당 장면에 적용한다. [메시 검증](../../tests/LabPet.Tests/MeshFactoryTests.cs)
- **구현 파일**: [IPetMeshFactory.cs](../../src/LabPet.Client/Rendering/IPetMeshFactory.cs), [ProceduralPetMeshFactory.cs](../../src/LabPet.Client/Rendering/ProceduralPetMeshFactory.cs), [PetAnimationController.cs](../../src/LabPet.Client/Rendering/PetAnimationController.cs)
- **동작 규칙**: `MeshBuilder` 기반 4종 캐릭터(`mochi_spirit`, `chibi_cat`, `fluffy_cloud`, `fluffy_puppy`)와 5개 커스텀 레이어를 조합하고 60fps `Transform3D`·`EmissiveMaterial`만 갱신한다.

## FT-03: 360도 3D 턴테이블 온보딩 및 외형 편집
- **구현 파일**: [OnboardingViewModel.cs](../../src/LabPet.Client/ViewModels/OnboardingViewModel.cs), [OnboardingWindow.xaml.cs](../../src/LabPet.Client/Views/OnboardingWindow.xaml.cs)
- **동작 규칙**: 최초 실행 시 온보딩 창을 띄우며, 완료 후에도 트레이 메뉴나 우클릭으로 외형·이름을 다시 편집할 수 있다.

## FT-04: 투명 바탕화면 펫 창 UX 및 시스템 트레이
- **구현 파일**: [PetWindowViewModel.cs](../../src/LabPet.Client/ViewModels/PetWindowViewModel.cs), [PetWindow.xaml.cs](../../src/LabPet.Client/Views/PetWindow.xaml.cs), [Win32WindowHelper.cs](../../src/LabPet.Client/Interop/Win32WindowHelper.cs), [App.xaml.cs](../../src/LabPet.Client/App.xaml.cs)
- **동작 규칙**: 단일 인스턴스 `Mutex`, 5px 클릭/드래그/흔들기 판정, 3D 히트 테스트 쓰다듬기, `WS_EX_TRANSPARENT` 클릭 투과, `H.NotifyIcon.Wpf` 트레이 메뉴를 제공한다.
- **중복 실행** 시 안내를 표시하고 두 번째 프로세스를 종료한다. 최초 인스턴스가 정상 종료한 후 다시 실행할 수 있다.
- **말풍선 및 이름표**는 업데이트 안내, 친구 신청, 최근 메시지 최대 5개를 내용 높이에 맞게 배치한다. 이름·레벨 바는 캐릭터 하단을 기준으로 정렬한다. [펫 창 XAML](../../src/LabPet.Client/Views/PetWindow.xaml)
- **외형 조절바**는 이름·레벨 바 아래에 작은 원형 손잡이로 표시하며, 크기와 투명도 값을 프로필에 저장한다. 크기 범위는 50~150%이며 외형 편집과 우클릭 메뉴에서도 적용한다. 투명도는 펫, 친구 오버레이와 입력창, 상단 말풍선에 적용한다. [펫 창 XAML](../../src/LabPet.Client/Views/PetWindow.xaml), [외형 편집 XAML](../../src/LabPet.Client/Views/OnboardingWindow.xaml)

## FT-05: `%AppData%\LabPet\` 분리 저장 및 스키마 마이그레이션
- **구현 파일**: [JsonAppDataStore.cs](../../src/LabPet.Client/Storage/JsonAppDataStore.cs), [StateMigrator.cs](../../src/LabPet.Client/Storage/StateMigrator.cs)
- **동작 규칙**: `.tmp` 기록 후 플러시 → `.bak` 갱신 → `File.Move(..., overwrite: true)` 원자적 저장 및 손상 시 `.bak` 자동 복구를 수행한다.
