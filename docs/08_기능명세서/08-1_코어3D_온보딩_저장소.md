[애니메이션 검증](../../tests/LabPet.Tests/PetAnimationAndEffectTests.cs)
- **크리스마스 트리 애니메이션**: 펫 우클릭 메뉴(`Viewport3D.ContextMenu`)와 트레이 우클릭 메뉴(`TrayIcon.ContextMenu`)에서 `🎄  크리스마스 트리`를 실행할 수 있다. 네이티브 진입점(`LabPet.Client.exe --christmas-tree <펫이름>`, [TerminalChristmasTreeService.cs](../../src/LabPet.Client/SystemIntegration/TerminalChristmasTreeService.cs))을 기본 실행 경로로 사용해 `conhost.exe` 또는 자체 `AllocConsole()`로 독립 콘솔 창을 띄우고 `ArgumentList`로 인자를 직접 전달해 셸 메타문자 해석을 방지한다. 3D 렌더링 코어([AsciiDepthSurface.cs](../../src/LabPet.Client/Rendering/Terminal3D/AsciiDepthSurface.cs), [AsciiAnsiFrameWriter.cs](../../src/LabPet.Client/Rendering/Terminal3D/AsciiAnsiFrameWriter.cs), [TerminalPointProjector.cs](../../src/LabPet.Client/Rendering/Terminal3D/TerminalPointProjector.cs))와 장면 엔진([ChristmasTreeGeometry.cs](../../src/LabPet.Client/Rendering/Terminal3D/ChristmasTreeGeometry.cs), [ChristmasTreeScene.cs](../../src/LabPet.Client/Rendering/Terminal3D/ChristmasTreeScene.cs), [ChristmasParticleField.cs](../../src/LabPet.Client/Rendering/Terminal3D/ChristmasParticleField.cs), [ChristmasTreeConsoleRunner.cs](../../src/LabPet.Client/SystemIntegration/ChristmasTreeConsoleRunner.cs))이 1열 고정폭 7비트 ASCII 밀도 램프(`.,':;-~=+!*ox#%&$@`), ANSI True Color 차분 출력, Z-Buffer 깊이 판정, Blinn-Phong 반사광·프레넬 림·코어 전구광으로 6단 층진 소나무 가지·눈서리·원형 3D 눈 지면·드레이프 황금 가랜드·54개 광택 오너먼트·회전된 6개 리본 선물 상자·5각 3D 별과 황금 광선·밤하늘 별빛·원근 눈송이·다단계 불꽃놀이를 실시간 렌더링한다. 최초 실행 시 `0~1초`(눈+지면) → `1~3초`(트리 성장) → `3~4초`(가랜드+선물) → `4~5초`(오너먼트+회전) → `5초`(별 점등) → `5초 이후`(무한 루프) 타임라인을 경과 시간 기준으로 진행하며, `Space`(회전 토글), `←/→`(회전 속도), `↑/↓`(확대/축소), `S`(눈 강도), `L`(조명 4모드), `F`(불꽃놀이), `R`(초기 등장 재시작), `F11`(최대화 전환), `Q`/`Esc`(종료 및 콘솔 모드·커서·버퍼 복구)를 지원한다. 중복 실행 시 [ChristmasTreeInstance.cs](../../src/LabPet.Client/SystemIntegration/ChristmasTreeInstance.cs)가 기존 콘솔 창을 활성화하고, 시작 완료는 첫 프레임 출력 신호([ChristmasTreeStartup.cs](../../src/LabPet.Client/SystemIntegration/ChristmasTreeStartup.cs))로 확인한다. - `.tmp` 기록과 플러시, `.bak` 갱신, 원자적 본 파일 교체를 사용한다. 친구 키와 성장 스냅샷은 현재 Windows 계정의 DPAPI로 보호한다. 0.3.16 최초 검사에서 레벨 50 초과와 코인 50,000 초과를 독립적으로 처리하며, 코인 초기화 때에만 보류 판돈·솔로 사다리·미적립 활동 보상을 정리한다. 검사 완료 기록은 성장 상태에 함께 봉인하고, 후속 버전이나 건너뛴 업데이트에서는 정책을 실행하지 않는다. 정상 본 파일, `.bak`, `profile.protection-v1`을 검증하며 손상된 파일은 보존한다. 모두 복구할 수 없으면 펫과 설정을 불러와 실행하고, 변경한 설정은 `profile.settings-recovery.json`에만 저장한다. 설정에서 정상 백업으로 재시도하거나 확인 후 성장만 초기화할 수 있다. [저장소 구현](../../src/LabPet.Client/Storage/JsonAppDataStore.cs), [저장·복구 테스트](../../tests/LabPet.Tests/StorageAndMigratorTests.cs)
- Windows 자동 실행 최신화([StartupRegistrationService.cs](../../src/LabPet.Client/SystemIntegration/StartupRegistrationService.cs))는 이미 Velopack 설치본이 등록된 상태에서 포터블·로컬 개발 빌드가 실행될 때 기존 설치 경로를 덮어쓰지 않는다.
- **스키마 `v1 → v2` 1회성 마이그레이션 ([StateMigrator.cs](../../src/LabPet.Client/Storage/StateMigrator.cs))**:
  - `profile.json`의 `schemaVersion < 2`인 기존 저장소를 로드할 때 1회에 한해 `SoloProgress.Level = 1`, `Xp = 0` 및 보상 대기 카운터(`PendingKeystrokesForReward`, `PendingMouseClicksForReward`, `PendingUptimeMinutesForReward`, `DailySocialRewardCoinsEarned`)를 `0`으로 초기화하고 `schemaVersion = 2`를 기록한다.
  - 보유 코인(`Coins >= 0` 보정)·누적 활동 통계(`TotalKeystrokes`, `TotalMouseClicks`, `TotalUptimeMinutes`, `CompletedPomodoros`)·친구 목록·외형·치장 항목은 그대로 보존하며, 기존 누적 활동량에 대한 소급 코인 지급은 하지 않는다. 이미 `schemaVersion == 2`로 저장된 뒤에는 재실행 시 레벨이나 진행도가 다시 초기화되지 않는다.
  - `friends.json` 로드 시 `FriendEntry.Intimacy`를 `0~9999` 범위로 정규화하고, `SoloProgress.PendingSoloLadderSession`에 진행 중 솔로 사다리 보드를 영속화해 재시작 시에도 재굴림·중복 정산을 차단한다. [경제·마이그레이션 검증](../../tests/LabPet.Tests/EconomyAndMigrationTests.cs)
