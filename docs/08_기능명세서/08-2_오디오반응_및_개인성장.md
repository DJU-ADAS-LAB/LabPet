# 08-2. 오디오 반응 및 개인 성장 기능명세

## FT-06: 시스템 루프백 오디오 FFT 분석기 (`Audio/`)
- **구현 파일**: [IAudioAnalyzer.cs](../../src/LabPet.Client/Audio/IAudioAnalyzer.cs), [AudioSpectrumProcessor.cs](../../src/LabPet.Client/Audio/AudioSpectrumProcessor.cs), [LoopbackAudioAnalyzer.cs](../../src/LabPet.Client/Audio/LoopbackAudioAnalyzer.cs)
- **동작 규칙**:
  - `WasapiLoopbackCapture`로 기본 재생 장치 출력을 1,024-point FFT(Hamming Window) 분석하여 Bass/Mid/Treble(0..1) 및 이동 평균 기반 적응형 비트 감지 수행
  - 마지막 샘플 수신 후 `120ms` 경과 시 무음 감쇠 적용
  - 활성 재생 장치 0개 환경에서도 예외 없이 안전 폴백
  - `IMMNotificationClient`로 스피커↔이어폰 핫스왑 감지 시 350ms 디바운스 후 자동 재연결

## FT-07: 종별 모션 클립 춤 애니메이션, 스켈레톤 IK · 스프링, 3D 풀링 이펙트 및 타이핑 반응
- **구현 파일**: [PetAnimationController.cs](../../src/LabPet.Client/Rendering/PetAnimationController.cs), [PetMotionClips.cs](../../src/LabPet.Client/Rendering/PetMotionClips.cs), [PetSkinInstance.cs](../../src/LabPet.Client/Rendering/PetSkinInstance.cs), [BlenderAssetPetMeshFactory.cs](../../src/LabPet.Client/Rendering/BlenderAssetPetMeshFactory.cs), [ProceduralPetMeshFactory.cs](../../src/LabPet.Client/Rendering/ProceduralPetMeshFactory.cs)
- **동작 규칙**:
  - 9종 재사용 모션 클립(`Idle`, `Groove`, `Bounce`, `HeadBob`, `PawDance`, `Turn`, `HappyJump`, `Reaction`, `Walk`), `SmoothStep` 클립 크로스페이드(최소 유지 1.5초로 비트 과장 억제), 비트 간격(`_beatInterval`) 추적, 기대(anticipation)·후속(follow-through) 점프 곡선, 프레임 시간 독립 지수 감쇠(`1 - exp(-damping * dt)`), 네트워크 스냅샷 지연·유실 감쇠 보간 지원
  - 리처드의 인사·기상·게임 승패·간식 클립은 반응 시간에 맞춰 끝까지 재생한다. 반복 클립과 단발 클립 사이를 전환하거나 같은 반응을 다시 시작하면 표시 중인 자세를 기준으로 다음 자세를 보간한다. [내장 클립 재생기](../../src/LabPet.Client/Rendering/AuthoredPetClips.cs)
  - **스켈레톤 IK · 임계 감쇠 스프링**: `PetSkinInstance`가 GLB 리그의 본 로컬 각도 제한·쿼터니언 Slerp 보간을 수행하며, 타이핑 손 도달 및 지면 발 접지(`ShadowY`)를 위한 2-Bone IK(`SolveChain`)와 귀·꼬리 끝 보조 흔들림을 위한 임계 감쇠 스프링(`Spring`)을 적용한다.
  - **종별 프로파일 차별화 (`SpeciesMotionProfile`)**: `mochi_spirit`(`Mochi`: 부피 보존 Squash & Stretch·탄성 바운스·미니 팔), `chibi_cat`(`Cat`: 앞발 리듬 춤·귀 쫑긋·S꼬리), `fluffy_cloud`(`Cloud`: 공중 부유 웨이브·회전·날개), `fluffy_puppy`(`Puppy`: 처진 귀 펄럭임·깃털 꼬리·앞다리 스텝), `hachiware`(`ChiikawaTrio`), `chiikawa`(`Shy`: 수줍은 반응 및 짧은 팔 리듬), `usagi`(`Rabbit`: 활발한 귀·점프 동작)
  - 3D 이펙트 풀링: 최대 8개(`MaxPooledParticles`) Blender 음표·별 메시를 할당 없이 재사용하며 알파 페이드 인/아웃·나선 상승 궤적·인사하기/기쁨 별 버스트 제공, 비활성 시 `Scale = 0` 및 `Alpha = 0` 처리
  - **타이핑·미니 키보드**: GLB 스켈레톤·OBJ·절차적 폴백 전 경로가 펫 앞 정중앙의 단일 3열 미니 키보드(`BuildTypingKeyboard`)를 공통 사용하며, GLB 리그에서는 몸체 전진(`OffsetZ`)·앞으로 숙임(`BodyPitch`)·어깨 비틀림(`BodyYaw`) 자세 보정과 함께 `PetSkinInstance`의 2-Bone IK(`SolveChain`) 및 손목 피치(`tipPitchRad`)로 단일 키보드 좌우 키를 향해 교대 타건한다(앞발형은 홈키 직접 타격, 짧은 옆팔·날개형은 전면 키보드 방향 호 타건). [키보드 메시](../../src/LabPet.Client/Rendering/ProceduralPetMeshFactory.cs), [애니메이션·이펙트 검증](../../tests/LabPet.Tests/PetAnimationAndEffectTests.cs), [스켈레톤 파이프라인 검증](../../tests/LabPet.Tests/BlenderAssetPipelineTests.cs)

- **동작 규칙**:
  - **코인 경제 및 수동 레벨업 (`Lv.1~99`)**: 기존 XP 기반 자동 레벨업을 제거하고, 사용자가 성장 페이지(`GrowthPageView`)에서 코인을 소비해 수동 레벨업한다. 비용 공식은 `100 + (level - 1) * 50`이며 `Lv.99`에서 `MAX LEVEL` 상태로 상한 도달 후 추가 차감을 막는다. 0.3.15의 평문 성장 상태 최초 이전에서 레벨이 50 초과이고 코인이 100,000 초과인 프로필만 레벨 1·0코인으로 초기화하며 보류 참가비와 진행 중 솔로 사다리를 정리한다. `PetEconomyService.TryLevelUp`은 `profile.SoloProgress` 잠금으로 원자적·동시성 안전하게 코인 차감 및 레벨 증가를 처리한다.
  - **코인 획득 비율 · 일일 소셜 상한 · 어뷰징 방지**:
    - 키보드 `200타 = +1 코인`, 마우스 클릭 `100회 = +1 코인`, 실사용 `10분 = +1 코인` (모두 잔여 누적 카운터를 프로필에 영속화)
    - 뽀모도로 집중 완료 시 `5분당 +2 코인` (`15분 = +6`, `25분 = +10`, `50분 = +20`)
    - 소셜 보상: 친구 메시지·인사하기 `+1 코인`, 빠른 이모지 반응 `0 코인`, 로컬 일자 기준 일일 소셜 코인 상한 `10코인` 영속화, 동일 `(FriendPetId, SocialRewardKind)` 15초 쿨다운
    - [ActivityAntiAbuseFilter.cs](../../src/LabPet.Client/Solo/ActivityAntiAbuseFilter.cs)로 `LLKHF_INJECTED`/`LLKHF_LOWER_IL_INJECTED`·`LLMHF_INJECTED`/`LLMHF_LOWER_IL_INJECTED` 주입 입력, 키를 누른 채 유지하는 OS 오토 리피트(`_pressedVkCodes`), 최소 간격 `40ms` 미만·초당 상한 초과 과속 입력을 제외한다. [SystemActivityStateMonitor.cs](../../src/LabPet.Client/Solo/SystemActivityStateMonitor.cs)로 세션 잠금·절전 모드·유휴 `60초` 이상 시간을 실사용 시간 적립에서 제외한다.
  - **축약 숫자 및 정밀 수치 분리 ([CompactNumberFormatter.cs](../../src/LabPet.Client/Formatting/CompactNumberFormatter.cs))**:
    - 큰 수치는 `K / M / B / T`(소수 최대 2자리, 불필요한 끝 0 제거, 반올림 `1000` 도달 시 상위 단위 승격, 시간 요약 `"1.25K시간"`)로 표시하며 툴팁으로 천 단위 구분 정확한 수치를 제공한다.
    - 레벨·친밀도·성장 페이지 레벨업 비용/잔액/부족분·초대 필요/보유/부족 코인·솔로 사다리 사용/획득/순손익 등 정밀 판단이 필요한 곳은 축약 없이 정확한 숫자를 표시한다.
  - **공용 친구 선택기 · 1:1 대기 화면**: 가위바위보·타이핑·공동 사다리가 공용 [FriendInvitePicker.xaml](../../src/LabPet.Client/Views/Controls/FriendInvitePicker.xaml) 카드 그리드(최초 미선택, 사용자/펫 이름 검색, 단일·다중 및 전체 선택/해제, `PetId` 기준 선택 유지, 오프라인 전환 시 타인 임의 선택 금지, 캐시된 `PetPortraitRenderer` 초상 재사용)를 공유하며, 1:1 초대 발신 시 [OneToOneInviteWaitView.xaml](../../src/LabPet.Client/Views/Games/OneToOneInviteWaitView.xaml)(좌측 내 펫 / 중앙 `VS` 맥동 애니메이션 / 우측 상대 펫 / 상단 게임·참가비 / 하단 남은 시간 바·초대 취소)로 전환한다.
  - 가위바위보 선택·공개 결과는 같은 손 이모지(✌️·✊·✋)를 사용한다. 대결과 1:1 대기 화면은 짧은 창에서 선택·취소 버튼까지 스크롤된다. 초대 배너가 표시되어 높이가 부족하면 게임 카드 목록도 스크롤한다. [가위바위보 화면](../../src/LabPet.Client/Views/Games/RpsGameView.xaml), [게임 카드 목록](../../src/LabPet.Client/Views/Games/GamesHubView.xaml), [WPF 배치 테스트](../../tests/LabPet.Tests/GameUiUxAndInviteTests.cs)
  - **단체 vs 솔로 연구실 사다리 분리**:
    - **단체 사다리** (`LadderGameView`): 9종 참가자 상태 카드, 4종 제한 시간(`초대 20초` / `방장 확정 60초` / `위치 선택 30초` / `재연결 유예 10초`), 방장 개별/전체 취소 및 참가자 자진 퇴장·2인 미만 전체 취소, 확정 후 이탈/위치 선택 시간 초과 시 전체 취소·환불, 게임 시작 이후 취소 차단, 구조화 상품(이름+수량 행)·3종 프리셋(`커피 쏘기`, `당첨 추첨`, `코인 잭팟`)·배분 진행 게이지·인원 불일치 시 방장 재조정 및 참가자 동의(`agree-prizes`) 절차 지원(무료 모드는 코인 변화 없음).
    - **솔로 사다리** (`SoloLadderView` · [SoloLadderEngine.cs](../../src/LabPet.Client/Games/SoloLadderEngine.cs)): 4칸 고정·1인 코인 미니게임(참가 코인 `10 / 30 / 50 / 100`, 불변 보상 `[꽝 0배, 꽝 0배, 본전 1배, 당첨 2.5배]` 균등 순열 = 기대 반환율 `87.5%`). 시작 전 사다리 비공개, 선택한 칸에 내 펫 초상 표시, 시작 시 내 펫이 선택한 단일 경로만 추적 애니메이션 후 도착 시 결과 공개 및 `PendingSoloLadderSession` 저장으로 창 닫기·재시작·이동 중 재굴림과 중복 정산을 차단한다.
  - **승리·패배 3D 반응 및 세션 정산**: 미니게임 승리 시 내 펫이 눈웃음을 지으며 두 번 뛰고, 패배 시 고개를 숙이고 눈물을 흘린다. 유료 멀티플레이 참가비는 `PendingGameWagers` 세션 키로 보류해 1회 정산·환불을 보장하고, 앱 재시작 시 미정산 보류를 반환한다.
