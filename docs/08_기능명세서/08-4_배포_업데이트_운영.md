# 08-4. 배포 · 자동 업데이트 · 운영 기능명세

## FT-11: Velopack 진입점 및 `UpdateService` (차분 자동 업데이트)
- **구현 파일**: [Program.cs](../../src/LabPet.Client/Program.cs), [UpdateSourceOptions.cs](../../src/LabPet.Client/Updates/UpdateSourceOptions.cs), [UpdateService.cs](../../src/LabPet.Client/Updates/UpdateService.cs)
- **동작 규칙**: WPF 초기화 전 `VelopackApp.Build().Run()` 호출, 시작 8초 후·5분 주기·LAN 상위 버전 감지·수동 확인(펫 우클릭 및 트레이 메뉴) 시 `SimpleWebSource`(기본) 또는 `GithubSource`에서 차분 업데이트 다운로드. Windows 부팅 자동 실행(`--autostart`) 시에는 무인 자동 재시작 적용, 일반 실행 중에는 펫 위 말풍선(`[업데이트 / 나중에]`) 표시

## FT-12: GitHub Actions 릴리스, 시작 프로그램·방화벽 자동 등록

- `main` 푸시와 대상 PR에서 별도 Windows 워크플로가 Node.js 24 기반 공식 액션(`actions/checkout@v6`, `actions/setup-dotnet@v5`)으로 복원, 빌드, 테스트를 실행한다. [Windows 검증 워크플로](../../.github/workflows/verify.yml)
- 방화벽 등록은 실행 파일 경로를 요구한다. 새 UDP·TCP 규칙을 모두 생성한 뒤 이전 규칙을 제거하고, 경로·서브넷·포트·프로토콜·방향·활성화·허용을 확인한다. [방화벽 등록 서비스](../../src/LabPet.Client/SystemIntegration/FirewallRegistrationService.cs)
- **구현 파일**: [release.yml](../../.github/workflows/release.yml), [StartupRegistrationService.cs](../../src/LabPet.Client/SystemIntegration/StartupRegistrationService.cs), [FirewallRegistrationService.cs](../../src/LabPet.Client/SystemIntegration/FirewallRegistrationService.cs), [SettingsPageView.xaml.cs](../../src/LabPet.Client/Views/Hub/Pages/SettingsPageView.xaml.cs), [AboutPageView.xaml.cs](../../src/LabPet.Client/Views/Hub/Pages/AboutPageView.xaml.cs)
- **동작 규칙**: `v*.*.*` 태그 푸시 시 `win-x64` self-contained 빌드 및 `vpk pack --runtime win-x64` 차분 릴리스 게시(`model.glb` 포함 `Assets/Models/**/*`), `HKCU\...\Run` 시작 프로그램(`--autostart`) 및 로컬 서브넷(`LocalSubnet`)·LabPet 실행 파일 제한(`program`)이 적용된 방화벽 규칙(UDP 45678~45679, TCP 45680 · `Profile Any`) 자동 등록·제거 훅 제공(수동 방화벽·네트워크 안내 UI는 통합 창 정리 시 제거됨)
