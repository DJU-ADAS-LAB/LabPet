## 동일 측정 코드로 비교한 1회 결과

`tools/PetPerfCompare/Program.cs`를 Baseline.csproj와 Current/Current.csproj가 공유한다. 기준 프로젝트는 `artifacts/aura-main-baseline`의 기존 소스를 참조하며 제품 소스를 수정하지 않는다. 이 폴더가 현재 원격 main과 일치하는지는 이번 측정에서 다시 확인하지 않았다.

조건: usagi/chiikawa/chibi_cat/fluffy_puppy 4펫, headset/music_notes, 214×224 투명창, 실제 데스크톱 카메라, 3초 워밍업 후 12초 측정. 활성은 16ms 타이머와 합성 오디오 입력, 유휴는 무음·40ms 타이머다. 실제 제품의 모든 유휴 정책을 실행한 것은 아니다.

| 조건 | 버전 | CPU | GPU | RAM (작업 집합) | UPDATE | COMPOSE |
|---|---|---:|---:|---:|---:|---:|
| 활성 | 기준 | 1.14% | 3.30% | 159.2 MiB | 40.0 Hz | 77.5 Hz |
| 활성 | 현재 | 1.13% | 3.63% | 159.4 MiB | 39.9 Hz | 77.1 Hz |
| 유휴 | 기준 | 0.54% | 2.86% | 158.3 MiB | 21.2 Hz | 60.3 Hz |
| 유휴 | 현재 | 0.58% | 3.06% | 159.1 MiB | 21.0 Hz | 59.1 Hz |

CPU는 논리 프로세서 수로 정규화한 프로세스 사용량, GPU는 해당 프로세스 3D 엔진 카운터 합계의 표본 평균이다. UPDATE/COMPOSE는 갱신/합성 이벤트 빈도이지 실제 표시 FPS가 아니다. 60/25FPS 목표 달성 증거가 아니며 단회 측정으로 개선·회귀를 확정하지 않는다. 활성 GPU +0.33%p, 유휴 +0.20%p와 RAM 증가가 관측되었다.
