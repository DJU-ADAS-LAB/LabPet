# 성장 증가 감시와 1회 초기화

## 적용 정책

- 0.3.16에서 처리 기록이 없는 프로필을 검사한다. 레벨 > 50 AND 코인 >= 50,000이면 레벨 1, XP 0, 코인 0으로 초기화한다. 판돈과 미완료 사다리 및 잔여 보상 카운터도 비운다. 이름, 외형, 친구, 누적 활동 기록은 유지한다.
- 대상이 아니어도 검사 완료 기록을 보호 저장하므로 같은 업데이트에서 반복 초기화하지 않는다. 현재 버전 조건은 0.3.16에 한정되며 이를 건너뛴 버전에서는 실행하지 않는다.
- 정상 경제 서비스 작업으로 설명되지 않은 양의 증가량을 분 단위로 누적한다. 최근 약 1시간(분 집계에 따른 경계 오차 포함)에 5,000코인 초과 OR 5레벨 초과이면 같은 성장 초기화를 수행한다.
- 정상 보상, 게임 지급·정산·환불, 코인 지불 레벨업과 소비·판돈 예약은 변경 전에 검사하고 처리 결과를 예상 상태에 반영한다. 따라서 정상 잭팟이나 모아둔 코인으로 연속 레벨업하는 경우는 속도가 빠르다는 이유만으로 초기화하지 않는다.
- 로드·저장 및 연결된 경제 변경 시 검사한다. 별도 상시 타이머나 서버 전송은 없다. 감시 기준과 적발 횟수·시각·사유는 기존 암호화 성장 데이터에 함께 저장한다. 시계 역행으로 기록을 지우지 않는다.

## 보호 범위

정상 경제 API 자체를 악용한 과다 지급은 이 감시의 설명되지 않은 증가에 포함되지 않는다. 비공개 리플렉션, 메모리/DLL 패치, 감시 상태까지 함께 변조하는 공격의 완전한 차단은 보장하지 않는다. 서버 권위 경제 검증을 대체하지 않는다.

## 검증

- Debug: 감시·경제·저장 관련 테스트 38개 통과(이후 소비·판돈 사전 검사와 통합 테스트 추가).
- 최종 Release: GrowthRate / Economy / Storage / Ladder / CoinGame 필터의 72개 테스트 전부 통과, 실패·건너뜀 0.
- 실제 임시 보호 저장소에서 조작 감지 후 재시작해도 레벨 1·코인 0과 적발 기록이 유지됨을 검증했다.
- 전체 UI 회귀 테스트의 통과를 의미하지 않는다. 설치 앱 교체나 업데이트 배포, 실제 사용자 데이터 초기화는 수행하지 않았다.
